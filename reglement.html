Règlement

Les règles de Santos Legacy RP

Elles existent pour garantir à tous une expérience sérieuse et immersive. En jouant sur le serveur, vous acceptez de les respecter.

Chapitre 1

Règlement général

Le présent règlement s’applique à l’ensemble des joueurs de Santos Legacy, aussi bien en jeu que sur les espaces communautaires officiels du serveur.

L’accès à Santos Legacy implique l’acceptation de ces règles ainsi que de la Charte Whitelist.

1.1 Respect et comportement

Tout joueur doit adopter un comportement respectueux envers les autres membres de la communauté.

Sont notamment interdits :

  • le harcèlement ;
  • les menaces HRP ;
  • les insultes visant directement la personne derrière le personnage ;
  • les propos discriminatoires ;
  • les attaques personnelles ;
  • la divulgation d’informations privées ;
  • les comportements volontairement toxiques ;
  • l’acharnement envers un joueur.

Les insultes peuvent exister dans un contexte Roleplay lorsqu’elles sont cohérentes avec une scène, mais elles ne doivent jamais devenir un prétexte pour attaquer personnellement un autre joueur.

1.2 Distinction RP / HRP

Chaque joueur doit être capable de différencier clairement ce qui appartient au Roleplay de ce qui appartient au Hors Roleplay.

Un conflit entre personnages ne doit pas se transformer en conflit entre joueurs.

De la même manière, une relation HRP avec un joueur ne doit pas influencer artificiellement les décisions de votre personnage.

Les informations obtenues hors du jeu ne doivent pas être utilisées en Roleplay sauf lorsqu’un système prévu par le serveur le permet explicitement.

1.3 Utilisation des moyens de communication externes

L’utilisation de Discord, streams, messages privés ou de tout autre moyen de communication externe afin d’obtenir ou transmettre des informations utilisables en RP est interdite.

Lorsqu’un joueur est connecté et actif en jeu, les communications liées à son personnage doivent passer par les moyens de communication disponibles dans l’univers du serveur.

Les salons Discord prévus spécifiquement pour certaines interactions RP constituent une exception lorsqu’ils sont officiellement mis à disposition par Santos Legacy.

1.4 Pseudonyme et identité

Le nom et le prénom d’un personnage doivent rester crédibles et adaptés à l’univers de Santos Legacy.

Sont interdits notamment :

  • les noms volontairement humoristiques ou trolls ;
  • les jeux de mots évidents ;
  • les noms de personnalités célèbres utilisés sans cohérence ;
  • les identités destinées uniquement à provoquer ;
  • l’usurpation volontaire de l’identité d’un autre joueur.

Le staff peut demander la modification d’une identité jugée incompatible avec l’univers du serveur.

1.5 Triche et logiciels externes

Toute utilisation d’un logiciel, fichier, modification ou procédé procurant un avantage injuste est strictement interdite.

Cela comprend notamment :

  • aimbot ;
  • wallhack ;
  • ESP ;
  • triggerbot ;
  • no recoil artificiel ;
  • macros donnant un avantage en jeu ;
  • modifications permettant de voir ou entendre des éléments normalement inaccessibles ;
  • menus de triche ;
  • injections ;
  • exploits externes.

La tentative d’utilisation ou la possession intentionnelle d’outils de triche dans le cadre du serveur peut également entraîner une sanction.

1.6 Exploitation de bugs

L’utilisation volontaire d’un bug ou d’une faille afin d’obtenir un avantage est interdite.

Cela concerne notamment :

  • duplication d’objets ou d’argent ;
  • duplication de véhicules ;
  • contournement d’un système serveur ;
  • exploitation d’une animation ;
  • utilisation d’une zone ou texture permettant d’éviter une mécanique prévue ;
  • exploitation d’un problème d’inventaire, de banque ou de métier.

Lorsqu’un joueur découvre une faille importante, il doit la signaler au staff.

Le fait de partager volontairement une faille avec d’autres joueurs dans le but de l’exploiter sera considéré comme aggravant.

1.7 Utilisation abusive des mécaniques GTA V

Toute mécanique disponible dans GTA V n’est pas nécessairement cohérente dans un environnement Roleplay.

Il est interdit d’utiliser volontairement les limites du jeu pour obtenir un avantage irréaliste.

Cela peut notamment concerner :

  • certaines animations ;
  • les changements rapides d’équipement ;
  • les déplacements irréalistes ;
  • l’utilisation abusive des sauts ;
  • les comportements permettant d’éviter artificiellement des tirs ou des interactions ;
  • toute mécanique détournée de son usage normal.

Le bon sens et la cohérence doivent toujours primer sur les possibilités techniques du jeu.

1.8 Déconnexion pendant une scène

Il est interdit de quitter volontairement le serveur afin d’éviter une scène ou ses conséquences.

Cela comprend notamment une déconnexion pendant :

  • une arrestation ;
  • une poursuite ;
  • une confrontation ;
  • un braquage ;
  • un enlèvement ;
  • une intervention médicale ;
  • une scène administrative ou judiciaire.

En cas de crash ou de problème technique, le joueur doit revenir dès que possible afin de poursuivre la scène.

Si le retour est impossible, il est recommandé de prévenir les personnes concernées ou le staff par les moyens prévus.

1.9 AFK

Un joueur ne doit pas rester AFK pendant une scène active.

Lorsqu’un joueur doit s’absenter, il doit autant que possible se placer dans un endroit cohérent et sécurisé.

L’AFK ne peut pas être utilisé pour :

  • éviter une interaction ;
  • empêcher une arrestation ;
  • protéger des biens ;
  • éviter les conséquences d’une scène ;
  • monopoliser volontairement une place sur le serveur.
1.10 Provocation gratuite

Il est interdit de provoquer volontairement d’autres joueurs ou certaines factions uniquement dans le but de déclencher une réaction.

Sont notamment concernés les comportements visant uniquement à provoquer :

  • les forces de l’ordre ;
  • les gangs ;
  • les organisations criminelles ;
  • les entreprises ;
  • les services publics.

Une provocation doit avoir une véritable justification Roleplay, et son auteur doit en accepter les conséquences.

1.11 Troll et comportements nuisibles

Les comportements dont l’objectif principal est de perturber l’expérience des autres joueurs sont interdits.

Cela comprend notamment :

  • interrompre volontairement des scènes sans raison RP ;
  • multiplier les comportements absurdes ;
  • utiliser des véhicules ou objets pour gêner volontairement ;
  • suivre constamment des joueurs afin de les déranger ;
  • provoquer des scènes uniquement pour attirer l’attention du staff ;
  • adopter volontairement un comportement incohérent pour faire rire au détriment du RP général.

L’humour reste autorisé lorsqu’il s’intègre naturellement dans une scène.

1.12 Publicité et promotion

La publicité pour un autre serveur FiveM ou une communauté concurrente est interdite sans autorisation de la direction.

Il est également interdit d’utiliser Santos Legacy afin de recruter des joueurs pour un autre projet.

Le partage de contenus personnels tels que Twitch, YouTube ou TikTok peut être autorisé dans les espaces prévus à cet effet.

1.13 Comptes et accès au serveur

Chaque joueur est responsable de son compte et de ses accès.

Il est interdit de :

  • prêter son compte à une autre personne afin qu’elle accède au serveur à votre place ;
  • contourner une sanction avec un autre compte ;
  • permettre volontairement à une personne non Whitelist d’utiliser votre accès ;
  • utiliser plusieurs identités ou comptes dans le but de contourner une restriction.

Toute tentative de contournement de sanction pourra entraîner une aggravation de celle-ci.

1.14 Économie et échanges

Toute transaction liée aux biens du serveur doit rester dans l’environnement prévu par Santos Legacy.

Il est strictement interdit d’échanger contre de l’argent réel :

  • de l’argent en jeu ;
  • des véhicules ;
  • des propriétés ;
  • des objets ;
  • des entreprises ;
  • des avantages RP ;
  • des informations ou services obtenus en jeu.

Les échanges de biens entre personnages doivent avoir une justification cohérente et ne doivent pas servir à contourner les systèmes économiques du serveur.

1.15 Transfert de biens entre personnages

Les biens, informations et relations d’un personnage appartiennent à ce personnage.

Il est interdit de transférer artificiellement vers un autre personnage :

  • de l’argent ;
  • des véhicules ;
  • des objets ;
  • des informations ;
  • des propriétés ;
  • des avantages ;
  • des contacts criminels ou professionnels,

dans le seul but de conserver un avantage acquis avec un autre personnage.

Toute exception devra être cohérente ou validée lorsque cela est nécessaire.

1.16 Intervention du staff

Lorsqu’un membre du staff intervient dans une situation, les joueurs doivent suivre ses instructions.

Une intervention staff suspend temporairement la scène lorsque cela est nécessaire.

Les débats prolongés ou règlements de compte ne doivent pas avoir lieu directement en jeu.

Si un joueur souhaite contester une décision, il doit utiliser les procédures prévues par le serveur.

1.17 Contestation d’une sanction

Tout joueur peut demander des explications concernant une sanction ou introduire une contestation selon les procédures mises en place par Santos Legacy.

Une contestation doit rester calme, argumentée et respectueuse.

Le harcèlement d’un membre du staff, la multiplication des tickets ou les tentatives de pression ne modifieront pas une décision et peuvent entraîner des sanctions supplémentaires.

1.18 Preuves et enregistrements

Dans certaines situations, le staff peut demander une preuve vidéo ou tout autre élément permettant de comprendre une scène.

Il est conseillé aux joueurs de disposer d’un système permettant d’enregistrer les dernières minutes de jeu.

Une vidéo volontairement coupée, modifiée ou présentée de manière trompeuse pourra ne pas être retenue comme preuve.

La falsification volontaire d’une preuve est strictement interdite.

1.19 Signalement d’un joueur

Lorsqu’une règle semble avoir été enfreinte, les joueurs doivent autant que possible terminer la scène avant de contacter le staff.

Il est déconseillé de casser une scène en lançant immédiatement une discussion HRP.

Le joueur concerné pourra ensuite effectuer un signalement accompagné des éléments nécessaires.

Une exception est possible lorsqu’une situation grave nécessite une intervention immédiate.

1.20 Bon sens

Le règlement ne peut pas prévoir chaque situation possible.

L’absence d’une interdiction écrite mot pour mot ne signifie pas qu’un comportement manifestement abusif devient automatiquement autorisé.

Lorsqu’un doute existe, chaque joueur doit privilégier : le fair-play, la cohérence Roleplay, le bon sens et l’expérience collective.

Le staff pourra intervenir lorsqu’un comportement détourne clairement l’esprit du règlement dans le but d’obtenir un avantage.

Le staff se réserve le droit de modifier ce règlement à tout moment. Les mises à jour sont annoncées sur le Discord.
