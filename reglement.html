Chapitre 1

Règlement général

Le présent règlement s’applique à l’ensemble des joueurs de Santos Legacy, aussi bien en jeu que sur les espaces communautaires officiels du serveur.

L’accès à Santos Legacy implique l’acceptation de ces règles ainsi que de la Charte Whitelist.

1.1 Respect et comportement

Tout joueur doit adopter un comportement respectueux envers les autres membres de la communauté.

Sont notamment interdits :

  • le harcèlement ;
  • les menaces HRP ;
  • les insultes visant directement la personne derrière le personnage ;
  • les propos discriminatoires ;
  • les attaques personnelles ;
  • la divulgation d’informations privées ;
  • les comportements volontairement toxiques ;
  • l’acharnement envers un joueur.

Les insultes peuvent exister dans un contexte Roleplay lorsqu’elles sont cohérentes avec une scène, mais elles ne doivent jamais devenir un prétexte pour attaquer personnellement un autre joueur.

1.2 Distinction RP / HRP

Chaque joueur doit être capable de différencier clairement ce qui appartient au Roleplay de ce qui appartient au Hors Roleplay.

Un conflit entre personnages ne doit pas se transformer en conflit entre joueurs.

De la même manière, une relation HRP avec un joueur ne doit pas influencer artificiellement les décisions de votre personnage.

Les informations obtenues hors du jeu ne doivent pas être utilisées en Roleplay sauf lorsqu’un système prévu par le serveur le permet explicitement.

1.3 Utilisation des moyens de communication externes

L’utilisation de Discord, streams, messages privés ou de tout autre moyen de communication externe afin d’obtenir ou transmettre des informations utilisables en RP est interdite.

Lorsqu’un joueur est connecté et actif en jeu, les communications liées à son personnage doivent passer par les moyens de communication disponibles dans l’univers du serveur.

Les salons Discord prévus spécifiquement pour certaines interactions RP constituent une exception lorsqu’ils sont officiellement mis à disposition par Santos Legacy.

1.4 Pseudonyme et identité

Le nom et le prénom d’un personnage doivent rester crédibles et adaptés à l’univers de Santos Legacy.

Sont interdits notamment :

  • les noms volontairement humoristiques ou trolls ;
  • les jeux de mots évidents ;
  • les noms de personnalités célèbres utilisés sans cohérence ;
  • les identités destinées uniquement à provoquer ;
  • l’usurpation volontaire de l’identité d’un autre joueur.

Le staff peut demander la modification d’une identité jugée incompatible avec l’univers du serveur.

1.5 Triche et logiciels externes

Toute utilisation d’un logiciel, fichier, modification ou procédé procurant un avantage injuste est strictement interdite.

Cela comprend notamment :

  • aimbot ;
  • wallhack ;
  • ESP ;
  • triggerbot ;
  • no recoil artificiel ;
  • macros donnant un avantage en jeu ;
  • modifications permettant de voir ou entendre des éléments normalement inaccessibles ;
  • menus de triche ;
  • injections ;
  • exploits externes.

La tentative d’utilisation ou la possession intentionnelle d’outils de triche dans le cadre du serveur peut également entraîner une sanction.

1.6 Exploitation de bugs

L’utilisation volontaire d’un bug ou d’une faille afin d’obtenir un avantage est interdite.

Cela concerne notamment :

  • duplication d’objets ou d’argent ;
  • duplication de véhicules ;
  • contournement d’un système serveur ;
  • exploitation d’une animation ;
  • utilisation d’une zone ou texture permettant d’éviter une mécanique prévue ;
  • exploitation d’un problème d’inventaire, de banque ou de métier.

Lorsqu’un joueur découvre une faille importante, il doit la signaler au staff.

Le fait de partager volontairement une faille avec d’autres joueurs dans le but de l’exploiter sera considéré comme aggravant.

1.7 Utilisation abusive des mécaniques GTA V

Toute mécanique disponible dans GTA V n’est pas nécessairement cohérente dans un environnement Roleplay.

Il est interdit d’utiliser volontairement les limites du jeu pour obtenir un avantage irréaliste.

Cela peut notamment concerner :

  • certaines animations ;
  • les changements rapides d’équipement ;
  • les déplacements irréalistes ;
  • l’utilisation abusive des sauts ;
  • les comportements permettant d’éviter artificiellement des tirs ou des interactions ;
  • toute mécanique détournée de son usage normal.

Le bon sens et la cohérence doivent toujours primer sur les possibilités techniques du jeu.

1.8 Déconnexion pendant une scène

Il est interdit de quitter volontairement le serveur afin d’éviter une scène ou ses conséquences.

Cela comprend notamment une déconnexion pendant :

  • une arrestation ;
  • une poursuite ;
  • une confrontation ;
  • un braquage ;
  • un enlèvement ;
  • une intervention médicale ;
  • une scène administrative ou judiciaire.

En cas de crash ou de problème technique, le joueur doit revenir dès que possible afin de poursuivre la scène.

Si le retour est impossible, il est recommandé de prévenir les personnes concernées ou le staff par les moyens prévus.

1.9 AFK

Un joueur ne doit pas rester AFK pendant une scène active.

Lorsqu’un joueur doit s’absenter, il doit autant que possible se placer dans un endroit cohérent et sécurisé.

L’AFK ne peut pas être utilisé pour :

  • éviter une interaction ;
  • empêcher une arrestation ;
  • protéger des biens ;
  • éviter les conséquences d’une scène ;
  • monopoliser volontairement une place sur le serveur.
1.10 Provocation gratuite

Il est interdit de provoquer volontairement d’autres joueurs ou certaines factions uniquement dans le but de déclencher une réaction.

Sont notamment concernés les comportements visant uniquement à provoquer :

  • les forces de l’ordre ;
  • les gangs ;
  • les organisations criminelles ;
  • les entreprises ;
  • les services publics.

Une provocation doit avoir une véritable justification Roleplay, et son auteur doit en accepter les conséquences.

1.11 Troll et comportements nuisibles

Les comportements dont l’objectif principal est de perturber l’expérience des autres joueurs sont interdits.

Cela comprend notamment :

  • interrompre volontairement des scènes sans raison RP ;
  • multiplier les comportements absurdes ;
  • utiliser des véhicules ou objets pour gêner volontairement ;
  • suivre constamment des joueurs afin de les déranger ;
  • provoquer des scènes uniquement pour attirer l’attention du staff ;
  • adopter volontairement un comportement incohérent pour faire rire au détriment du RP général.

L’humour reste autorisé lorsqu’il s’intègre naturellement dans une scène.

1.12 Publicité et promotion

La publicité pour un autre serveur FiveM ou une communauté concurrente est interdite sans autorisation de la direction.

Il est également interdit d’utiliser Santos Legacy afin de recruter des joueurs pour un autre projet.

Le partage de contenus personnels tels que Twitch, YouTube ou TikTok peut être autorisé dans les espaces prévus à cet effet.

1.13 Comptes et accès au serveur

Chaque joueur est responsable de son compte et de ses accès.

Il est interdit de :

  • prêter son compte à une autre personne afin qu’elle accède au serveur à votre place ;
  • contourner une sanction avec un autre compte ;
  • permettre volontairement à une personne non Whitelist d’utiliser votre accès ;
  • utiliser plusieurs identités ou comptes dans le but de contourner une restriction.

Toute tentative de contournement de sanction pourra entraîner une aggravation de celle-ci.

1.14 Économie et échanges

Toute transaction liée aux biens du serveur doit rester dans l’environnement prévu par Santos Legacy.

Il est strictement interdit d’échanger contre de l’argent réel :

  • de l’argent en jeu ;
  • des véhicules ;
  • des propriétés ;
  • des objets ;
  • des entreprises ;
  • des avantages RP ;
  • des informations ou services obtenus en jeu.

Les échanges de biens entre personnages doivent avoir une justification cohérente et ne doivent pas servir à contourner les systèmes économiques du serveur.

1.15 Transfert de biens entre personnages

Les biens, informations et relations d’un personnage appartiennent à ce personnage.

Il est interdit de transférer artificiellement vers un autre personnage :

  • de l’argent ;
  • des véhicules ;
  • des objets ;
  • des informations ;
  • des propriétés ;
  • des avantages ;
  • des contacts criminels ou professionnels,

dans le seul but de conserver un avantage acquis avec un autre personnage.

Toute exception devra être cohérente ou validée lorsque cela est nécessaire.

1.16 Intervention du staff

Lorsqu’un membre du staff intervient dans une situation, les joueurs doivent suivre ses instructions.

Une intervention staff suspend temporairement la scène lorsque cela est nécessaire.

Les débats prolongés ou règlements de compte ne doivent pas avoir lieu directement en jeu.

Si un joueur souhaite contester une décision, il doit utiliser les procédures prévues par le serveur.

1.17 Contestation d’une sanction

Tout joueur peut demander des explications concernant une sanction ou introduire une contestation selon les procédures mises en place par Santos Legacy.

Une contestation doit rester calme, argumentée et respectueuse.

Le harcèlement d’un membre du staff, la multiplication des tickets ou les tentatives de pression ne modifieront pas une décision et peuvent entraîner des sanctions supplémentaires.

1.18 Preuves et enregistrements

Dans certaines situations, le staff peut demander une preuve vidéo ou tout autre élément permettant de comprendre une scène.

Il est conseillé aux joueurs de disposer d’un système permettant d’enregistrer les dernières minutes de jeu.

Une vidéo volontairement coupée, modifiée ou présentée de manière trompeuse pourra ne pas être retenue comme preuve.

La falsification volontaire d’une preuve est strictement interdite.

1.19 Signalement d’un joueur

Lorsqu’une règle semble avoir été enfreinte, les joueurs doivent autant que possible terminer la scène avant de contacter le staff.

Il est déconseillé de casser une scène en lançant immédiatement une discussion HRP.

Le joueur concerné pourra ensuite effectuer un signalement accompagné des éléments nécessaires.

Une exception est possible lorsqu’une situation grave nécessite une intervention immédiate.

1.20 Bon sens

Le règlement ne peut pas prévoir chaque situation possible.

L’absence d’une interdiction écrite mot pour mot ne signifie pas qu’un comportement manifestement abusif devient automatiquement autorisé.

Lorsqu’un doute existe, chaque joueur doit privilégier : le fair-play, la cohérence Roleplay, le bon sens et l’expérience collective.

Le staff pourra intervenir lorsqu’un comportement détourne clairement l’esprit du règlement dans le but d’obtenir un avantage.

Chapitre 2

Règles fondamentales du Roleplay

Ce chapitre regroupe les notions fondamentales du Roleplay sur Santos Legacy.

Chaque joueur Whitelist est considéré comme ayant pris connaissance de ces règles et doit être capable de les appliquer naturellement en jeu.

2.1 Metagaming

Le Metagaming consiste à utiliser en Roleplay une information obtenue en dehors du jeu ou par un moyen auquel votre personnage n’a normalement pas accès.

Interdit

  • regarder un stream pour connaître la position d’un joueur ;
  • utiliser une information obtenue sur Discord dans une scène RP ;
  • reconnaître un personnage uniquement grâce à son pseudo affiché ;
  • utiliser une conversation HRP pour obtenir un avantage en jeu ;
  • transmettre des informations par Discord pendant une scène.

Autorisé

Une information peut être utilisée si votre personnage l’a réellement obtenue en RP par un moyen cohérent : discussion, téléphone, radio, enquête, témoin, document ou système prévu par le serveur.

Votre personnage ne sait que ce qu’il a réellement appris en jeu.

2.2 Powergaming

Le Powergaming consiste à réaliser ou imposer une action irréaliste, impossible ou ne laissant aucune possibilité cohérente de réaction aux autres joueurs.

Exemples interdits

  • continuer à courir normalement après plusieurs blessures graves ;
  • effectuer des actions physiquement impossibles ;
  • forcer une action sur un autre joueur sans lui laisser la possibilité de réagir ;
  • profiter des limites techniques de GTA V pour réaliser une action incohérente ;
  • sortir instantanément un objet ou une arme dans une situation où cela serait physiquement impossible.

Les possibilités techniques du jeu ne déterminent pas ce qui est réaliste en RP.

2.3 Force RP

Le Force RP consiste à imposer une scène, une conséquence ou une décision à un autre joueur sans lui laisser une marge de jeu raisonnable.

Exemple

Dire :

« Je te frappe, tu tombes inconscient et tu oublies tout. »

est une action imposée.

Une formulation laissant la possibilité de réaction est préférable lorsqu’une mécanique du serveur ne détermine pas directement le résultat.

Le Roleplay doit rester une interaction, pas une narration imposée à sens unique.

2.4 Fear RP

Votre personnage doit avoir conscience du danger et craindre raisonnablement pour sa vie.

Lorsqu’une menace crédible existe, votre personnage doit adapter son comportement.

Exemple

Si plusieurs individus armés braquent votre personnage à très courte distance et qu’il n’a aucune possibilité raisonnable de fuite, sortir soudainement une arme pour tenter de tous les abattre pourra être considéré comme un manque de Fear RP.

Le Fear RP ne signifie cependant pas qu’un personnage doit systématiquement obéir à tout.

La réaction doit dépendre :

  • du contexte ;
  • de la personnalité du personnage ;
  • de la menace ;
  • des possibilités réalistes de fuite ou de défense.
2.5 No Fear

Le No Fear correspond au fait d’ignorer volontairement une menace évidente ou de considérer son personnage comme invincible.

Sont notamment concernés :

  • provoquer constamment des personnes armées sans raison ;
  • se jeter volontairement dans une situation mortelle ;
  • ignorer une arme pointée sur soi sans justification ;
  • multiplier les comportements suicidaires simplement parce que le joueur sait qu’il pourra revenir.

Votre personnage tient à sa vie.

2.6 Pain RP

Votre personnage doit interpréter les blessures et la douleur de manière cohérente.

La gravité du comportement attendu dépend notamment :

  • de la nature de la blessure ;
  • du nombre de blessures ;
  • de la localisation ;
  • de la situation ;
  • des soins reçus.

Une blessure importante doit avoir un impact sur la façon de parler, marcher, courir ou agir.

Le Pain RP doit rester raisonnable : l’objectif n’est pas de simuler médicalement chaque blessure, mais de ne pas agir comme si rien ne s’était passé.

2.7 No Pain

Le No Pain consiste à ignorer volontairement les conséquences physiques d’une blessure importante.

Exemples

  • sprinter immédiatement après avoir été gravement blessé ;
  • reprendre un combat comme si de rien n’était ;
  • conduire normalement après une blessure sérieuse sans aucune interprétation ;
  • continuer une scène physique intense malgré un état médical incohérent.
2.8 Mass RP

Los Santos est considérée comme une ville vivante et peuplée, même lorsque les rues semblent vides en raison des limites techniques du jeu.

Vous devez prendre en compte la présence fictive :

  • de citoyens ;
  • de témoins ;
  • de salariés ;
  • de caméras ;
  • de services publics ;
  • de forces de l’ordre ;
  • de sécurité privée.

Exemple

Commettre un meurtre en plein centre-ville à midi simplement parce qu’aucun joueur n’est visible ne signifie pas que votre personnage agit dans une rue totalement vide.

Le contexte de la zone doit toujours être pris en compte.

2.9 Win RP

Le Win RP consiste à chercher systématiquement à gagner une scène au détriment de sa cohérence ou de l’expérience des autres joueurs.

Cela peut notamment se traduire par :

  • refuser toute conséquence ;
  • exploiter chaque détail du règlement uniquement pour obtenir un avantage ;
  • chercher constamment la confrontation gagnante ;
  • contester chaque défaite RP ;
  • privilégier les mécaniques du jeu au développement de la scène.

Santos Legacy n’est pas un jeu compétitif.

Une défaite peut produire un excellent Roleplay.

2.10 Fair-play

Chaque joueur doit être capable de reconnaître lorsqu’une action, bien que techniquement possible, serait injuste ou nuisible à la qualité d’une scène.

Le fair-play implique notamment de :

  • laisser une possibilité raisonnable de réaction ;
  • ne pas exploiter volontairement les difficultés techniques d’un autre joueur ;
  • éviter de chercher constamment la faille réglementaire ;
  • accepter une situation lorsqu’elle est cohérente ;
  • privilégier la qualité de la scène à son résultat.
2.11 Freekill / RDM

Le Freekill, également appelé RDM, consiste à tuer ou gravement attaquer un joueur sans justification Roleplay suffisante.

Toute agression grave doit avoir :

  • un contexte ;
  • une raison ;
  • une progression cohérente de la scène.

Un simple désaccord, une insulte légère ou une provocation mineure ne justifie pas automatiquement l’utilisation d’une arme létale.

2.12 Vehicle Deathmatch / VDM

Le VDM consiste à utiliser volontairement un véhicule comme une arme sans justification RP cohérente.

Il est notamment interdit de :

  • écraser volontairement un joueur sans contexte ;
  • multiplier les tentatives pour renverser quelqu’un ;
  • utiliser son véhicule comme arme principale lors d’un conflit sans justification.

Certaines situations peuvent permettre l’usage d’un véhicule dans une action défensive ou de fuite, mais cela doit rester cohérent, proportionné et exceptionnel.

2.13 Car Kill

Il est interdit de maintenir volontairement un véhicule sur un joueur afin de l’empêcher de se relever ou de provoquer sa mort.

Un accident peut arriver.

Le fait de revenir volontairement sur une personne au sol afin de l’achever avec un véhicule constitue une infraction grave.

2.14 Revenge Kill

Le Revenge Kill consiste à rechercher volontairement une personne afin de se venger immédiatement après une scène au cours de laquelle votre personnage a été grièvement blessé, mis inconscient ou a perdu la possibilité logique de poursuivre le conflit.

Une revanche doit être construite à travers du Roleplay et dépendre des informations dont votre personnage dispose réellement.

2.15 Retour sur zone

Après avoir été évacué d’une scène grave, un joueur ne doit pas revenir immédiatement sur les lieux simplement pour reprendre l’action.

Cela concerne notamment :

  • les fusillades ;
  • les braquages ;
  • les conflits entre organisations ;
  • les interventions policières ;
  • les scènes ayant provoqué une incapacité importante.

Le personnage doit laisser la scène évoluer sans lui lorsque son état ou son évacuation le justifie.

2.16 New Life Rule

Lorsqu’un personnage subit une situation médicale extrêmement grave, il doit respecter les conséquences déterminées par les systèmes et règles du serveur.

Être inconscient ne signifie pas automatiquement oublier toute la scène.

La perte de mémoire ne doit pas être utilisée librement pour :

  • éviter des conséquences ;
  • protéger des informations ;
  • annuler une scène défavorable.

Lorsque le serveur prévoit une mécanique ou une règle spécifique liée à la mémoire, celle-ci doit être respectée.

2.17 Cop Bait

Le Cop Bait consiste à provoquer volontairement les forces de l’ordre uniquement dans le but d’obtenir une poursuite ou une intervention.

Exemples interdits

  • passer constamment devant un commissariat en provoquant les policiers ;
  • effectuer volontairement des infractions répétées devant eux afin d’être poursuivi ;
  • insulter gratuitement un policier uniquement pour déclencher une scène ;
  • tirer en l’air sans raison uniquement pour attirer la police.

Une interaction conflictuelle avec les forces de l’ordre doit avoir un véritable contexte RP.

2.18 Bait d’organisation

La même logique s’applique aux gangs, organisations et autres groupes.

Il est interdit de provoquer artificiellement une organisation uniquement afin de déclencher un conflit, une fusillade ou une réaction.

Les conflits entre groupes doivent avoir une origine RP et une progression identifiable.

2.19 Stream Sniping / Streamhack

Il est strictement interdit d’utiliser le stream d’un joueur afin d’obtenir une information ou un avantage.

Cela comprend notamment :

  • sa position ;
  • ses conversations ;
  • son inventaire ;
  • l’identité de ses interlocuteurs ;
  • ses projets ;
  • ses déplacements ;
  • toute information non connue de votre personnage.

Le simple fait de disposer d’une information obtenue grâce à un stream peut suffire à rendre son utilisation interdite.

2.20 Chicken Run / mouvements irréalistes

Les mouvements volontairement utilisés afin d’exploiter les mécaniques de GTA V pendant un combat sont interdits lorsqu’ils deviennent irréalistes.

Cela comprend notamment :

  • courir en zigzag de manière excessive afin d’éviter les tirs ;
  • enchaîner des changements de direction irréalistes ;
  • sauter constamment pendant un combat ;
  • utiliser des animations afin d’altérer artificiellement sa hitbox.

Les déplacements doivent rester cohérents avec une situation réelle.

2.21 Bunny Hop

L’utilisation répétée du saut afin de se déplacer plus rapidement ou d’obtenir un avantage est interdite.

Sauter pour franchir normalement un obstacle reste évidemment autorisé.

2.22 Combat Logging

Le Combat Logging consiste à se déconnecter volontairement afin d’éviter :

  • un combat ;
  • une arrestation ;
  • une perte ;
  • une fouille ;
  • une scène ;
  • une conséquence RP.

En cas de crash réel, le joueur doit tenter de revenir sur le serveur dès que possible.

2.23 OOC en scène

Les discussions Hors Roleplay doivent être limitées au strict nécessaire pendant une scène.

Les expressions telles que :

  • « je vais appeler un admin » ;
  • « c’est interdit par le règlement » ;
  • « je vais faire un ticket » ;
  • « tu fais du PowerGaming »,

ne doivent pas être utilisées pour interrompre ou influencer une scène.

Dans la majorité des cas : terminez la scène, enregistrez les faits puis contactez le staff ensuite.

Une intervention immédiate reste possible dans une situation grave.

2.24 Refus de scène

Un joueur ne peut pas décider unilatéralement qu’une scène ne l’intéresse pas lorsqu’elle est cohérente et qu’elle respecte le règlement.

En revanche, aucune règle ne permet de forcer une personne à participer à des contenus sensibles ou incompatibles avec les limites fixées par le serveur.

Le staff pourra intervenir lorsque la légitimité d’une scène fait l’objet d’un doute important.

2.25 Cohérence avant victoire

Dans toute situation non expressément prévue par le règlement, la logique suivante doit être appliquée :

Cohérence RP → Fair-play → Possibilité de réaction → Conséquences → Résultat de la scène

Le résultat final doit toujours être secondaire par rapport à la qualité du Roleplay produit.

Règle essentielle

Une infraction RP ne doit pas être jugée uniquement à partir d’une action isolée.

Le contexte complet de la scène doit toujours être pris en considération.

Une action peut être cohérente dans une situation et totalement incohérente dans une autre.

Chapitre 3

Personnage, blessures et mort RP

Chaque personnage présent sur Santos Legacy doit être considéré comme une personne à part entière, avec une identité, une histoire, des relations, des limites et des conséquences.

Les blessures, traumatismes et événements majeurs doivent avoir un impact cohérent sur son évolution.

3.1 Création du personnage

Chaque personnage doit disposer d’une identité crédible et adaptée à l’univers du serveur.

Lors de sa création, le joueur doit réfléchir au minimum à :

  • son origine ;
  • son âge ;
  • son parcours ;
  • son caractère ;
  • ses motivations ;
  • ses compétences ;
  • ses limites ;
  • ses éventuelles relations.

Un personnage ne doit pas être conçu uniquement dans le but d’obtenir rapidement un avantage économique, criminel ou professionnel.

3.2 Cohérence du passé

L’histoire d’un personnage doit rester réaliste et proportionnée à ce qu’il est capable de démontrer en jeu.

Il est par exemple déconseillé de créer un personnage présenté comme :

  • ancien chef d’un cartel international ;
  • ancien agent secret surentraîné ;
  • tueur professionnel mondialement connu ;
  • milliardaire ayant tout abandonné ;
  • expert absolu dans plusieurs domaines sans justification.

Un passé exceptionnel peut exister, mais il doit rester crédible et ne doit pas servir à justifier automatiquement des capacités supérieures aux autres joueurs.

3.3 Évolution du personnage

Un personnage doit évoluer progressivement.

Ses décisions, relations, compétences et ambitions doivent être construites à travers les scènes vécues en jeu.

Un changement majeur de comportement doit pouvoir être expliqué par son histoire récente.

Exemple

Un personnage jusque-là totalement éloigné du milieu criminel ne devrait pas devenir trafiquant, braqueur puis membre d’une organisation importante en quelques heures sans véritable développement RP.

3.4 Séparation entre les personnages

Si Santos Legacy autorise plusieurs personnages, chacun d’eux doit être considéré comme une identité totalement indépendante.

Il est interdit de transférer volontairement d’un personnage à l’autre :

  • des connaissances ;
  • des informations ;
  • des relations ;
  • des biens ;
  • des rancœurs ;
  • des objectifs ;
  • des avantages obtenus grâce à un autre personnage.

Votre nouveau personnage ne connaît pas automatiquement les personnes connues par votre précédent personnage.

3.5 Liens entre ses propres personnages

Un joueur ne doit pas utiliser plusieurs de ses personnages afin de créer artificiellement un avantage pour lui-même.

Il est notamment interdit de créer un second personnage uniquement pour :

  • récupérer les biens du premier ;
  • venger le premier ;
  • transmettre des informations ;
  • protéger une organisation ;
  • contourner une sanction ou une conséquence ;
  • influencer une scène concernant directement son autre personnage.
3.6 Compétences du personnage

Votre personnage ne maîtrise pas automatiquement toutes les compétences simplement parce que vous, joueur, savez les utiliser.

Certaines connaissances doivent être cohérentes avec son parcours.

Cela concerne notamment :

  • la médecine ;
  • la mécanique ;
  • les armes ;
  • l’informatique ;
  • le droit ;
  • les techniques policières ;
  • certaines activités criminelles spécialisées.

La progression RP doit être privilégiée.

3.7 Blessures

Toute blessure importante doit être prise en compte dans l’interprétation du personnage.

La réaction dépend de :

  • la gravité de la blessure ;
  • sa localisation ;
  • l’arme ou l’accident concerné ;
  • l’état général du personnage ;
  • les soins reçus.

Une blessure ne disparaît pas simplement parce qu’une scène vient de se terminer.

3.8 Conséquences après une blessure

Après une blessure importante, un joueur doit adapter temporairement son comportement.

Selon la situation, cela peut notamment impliquer :

  • des difficultés à courir ;
  • une mobilité réduite ;
  • des douleurs ;
  • une incapacité temporaire à reprendre un combat ;
  • une période de récupération ;
  • un suivi médical.

Les conséquences doivent rester raisonnables et adaptées à la gravité de la scène.

3.9 Accident de la route

Un accident important doit être interprété.

Percuter un mur, effectuer plusieurs tonneaux ou subir une collision violente ne doit pas systématiquement être suivi d’une reprise immédiate de la conduite comme si rien ne s’était passé.

La réaction doit dépendre de la violence de l’accident et du contexte.

3.10 Inconscience

Lorsqu’un personnage tombe inconscient, il ne peut plus participer normalement à la scène.

Il est notamment interdit de :

  • communiquer des informations ;
  • utiliser volontairement son téléphone ;
  • utiliser sa radio ;
  • donner la position de ses adversaires ;
  • transmettre des informations via Discord ;
  • réagir à des éléments que le personnage ne pourrait pas percevoir.
3.11 Informations entendues pendant l’inconscience

Un personnage totalement inconscient ne doit pas utiliser ultérieurement des informations entendues pendant cette période.

Si une mécanique ou une situation permet au personnage de rester partiellement conscient, le contexte devra être pris en considération.

Le joueur doit toujours privilégier la cohérence plutôt que l’avantage.

3.12 Coma et hospitalisation

Une hospitalisation importante doit avoir des conséquences RP raisonnables.

Un joueur ne devrait pas sortir d’un état critique puis retourner immédiatement :

  • dans une fusillade ;
  • dans un braquage ;
  • dans une poursuite ;
  • dans un conflit violent.

Une période de récupération doit être interprétée lorsque la gravité de la scène le justifie.

3.13 Perte de mémoire

Une perte de mémoire ne peut pas être décidée librement uniquement pour éviter une conséquence.

Le fait d’être blessé ou inconscient n’entraîne pas automatiquement l’oubli de toute une scène.

Toute amnésie importante doit être cohérente avec la situation ou résulter d’une règle, d’une mécanique ou d’une décision RP adaptée.

3.14 Reconnaissance après une scène

Si votre personnage a raisonnablement pu identifier une personne avant de perdre connaissance, il peut conserver cette information sauf élément RP indiquant le contraire.

À l’inverse, il ne peut pas inventer une identité qu’il n’a jamais réellement découverte.

Le port d’un masque, la voix, la luminosité, la distance et le contexte doivent être pris en compte.

3.15 Masques et reconnaissance

Le port d’un masque ne rend pas automatiquement un personnage totalement méconnaissable dans toutes les situations.

Une reconnaissance peut éventuellement être justifiée par plusieurs éléments cohérents, par exemple :

  • une voix extrêmement familière ;
  • une particularité physique évidente ;
  • une tenue connue ;
  • un comportement caractéristique ;
  • des informations précédemment obtenues en RP.

La reconnaissance ne doit cependant jamais être automatique simplement parce que le joueur connaît l’identité HRP de la personne.

3.16 Blessures volontaires

Un joueur ne doit pas utiliser volontairement les systèmes de blessures ou de coma afin d’échapper à une situation.

Se faire volontairement tuer ou blesser afin d’éviter :

  • une arrestation ;
  • un interrogatoire ;
  • une dette ;
  • une fouille ;
  • une conséquence RP,

pourra être considéré comme un refus de scène.

3.17 Suicide RP

Les scènes de suicide doivent être traitées avec sérieux.

Elles ne doivent jamais être utilisées comme :

  • moyen d’éviter une arrestation ;
  • moyen d’effacer les conséquences d’une scène ;
  • troll ;
  • méthode de changement rapide de personnage.

Toute scène ayant pour objectif la mort définitive d’un personnage doit respecter les règles de Mort RP prévues par Santos Legacy.

3.18 Mort RP

Une Mort RP correspond à la fin définitive de l’histoire d’un personnage.

Une fois validée et jouée, elle est irréversible sauf décision exceptionnelle de la direction en cas de problème manifeste.

Le personnage concerné ne pourra plus être utilisé.

Ses relations, connaissances et informations ne peuvent pas être simplement transférées vers un nouveau personnage.

3.19 Mort RP volontaire

Un joueur peut décider de mettre fin définitivement à l’histoire de son propre personnage.

La scène doit cependant être préparée de manière cohérente et ne doit pas servir uniquement à effacer :

  • des dettes ;
  • un casier judiciaire ;
  • des ennemis ;
  • des obligations ;
  • des conséquences importantes.

Selon l’importance du personnage et de la scène, une validation préalable du staff pourra être demandée.

3.20 Mort RP imposée

La mort définitive d’un personnage ne doit pas devenir une sanction arbitraire utilisée pour gagner un conflit.

Une Mort RP imposée devra toujours reposer sur un contexte extrêmement sérieux et sur la procédure définie par Santos Legacy.

Une organisation ou un joueur ne peut pas décider seul que le personnage d’une autre personne est définitivement mort.

La validation du staff peut être requise avant toute Mort RP imposée.

3.21 Demande de Mort RP

Lorsqu’une Mort RP concernant un autre personnage est envisagée, la demande devra présenter un dossier suffisamment construit.

Celui-ci pourra notamment comprendre :

  • le contexte du conflit ;
  • l’historique des scènes ;
  • les motivations ;
  • les éléments de preuve ;
  • les alternatives déjà tentées ;
  • les conséquences RP prévues.

L’objectif est de réserver la Mort RP aux histoires importantes et non aux conflits mineurs.

3.22 Mort RP et organisations

L’appartenance à une organisation criminelle peut exposer un personnage à des conséquences importantes.

Cependant, rejoindre une organisation ne signifie pas automatiquement accepter qu’un autre joueur puisse décider librement de la mort définitive du personnage.

Les règles spécifiques aux organisations pourront prévoir certaines conditions supplémentaires.

3.23 Nouveau personnage après une Mort RP

Après une Mort RP, un nouveau personnage doit repartir avec sa propre histoire.

Il ne peut pas automatiquement :

  • récupérer les biens de l’ancien personnage ;
  • rejoindre immédiatement son ancienne organisation ;
  • connaître ses anciens alliés ;
  • connaître ses ennemis ;
  • poursuivre ses conflits ;
  • chercher à le venger.

Le nouveau personnage doit construire ses propres relations en jeu.

3.24 Testament et héritage

Un héritage RP peut éventuellement être reconnu lorsque celui-ci a été construit de manière cohérente avant la mort du personnage.

Cependant, un testament ne doit pas devenir un moyen de transférer artificiellement la totalité d’un patrimoine vers son propre nouveau personnage.

Les transferts importants pourront être soumis à validation du staff.

3.25 Changement radical de personnage

Un joueur souhaitant modifier profondément l’identité, la personnalité ou l’histoire de son personnage doit conserver une certaine continuité.

Lorsque le changement est trop important pour rester crédible, la création d’un nouveau personnage peut être préférable.

3.26 Conséquences psychologiques

Les événements importants vécus par un personnage peuvent également influencer son comportement.

Cela peut concerner :

  • une agression ;
  • un enlèvement ;
  • une perte importante ;
  • un accident ;
  • la mort d’un proche ;
  • une longue période de détention.

Aucune interprétation psychologique précise n’est imposée, mais ignorer systématiquement tous les événements majeurs peut nuire à la cohérence du personnage.

3.27 Cohérence médicale

Les joueurs ne doivent pas inventer arbitrairement des conséquences médicales extrêmement graves uniquement pour influencer une scène.

De la même manière, un joueur ne peut pas décider lui-même qu’une blessure normalement grave n’a absolument aucun effet.

Les décisions médicales importantes doivent être jouées avec les professionnels de santé présents sur le serveur lorsque cela est possible.

3.28 EMS et diagnostic

Lorsqu’un membre des services médicaux prend en charge votre personnage, son intervention doit être respectée dans les limites du RP.

Un joueur ne doit pas constamment contredire un diagnostic uniquement afin de reprendre plus rapidement ses activités.

Les EMS doivent eux aussi laisser une marge d’interprétation raisonnable au joueur concernant son personnage.

3.29 Retour à l’action

Après une scène ayant provoqué des blessures importantes, le retour à une activité dangereuse doit rester cohérent.

Il peut être demandé au joueur de laisser passer une période raisonnable avant de reprendre :

  • une fusillade ;
  • un braquage ;
  • une activité criminelle physique ;
  • une intervention policière importante.

Le contexte et la gravité des blessures doivent primer sur une durée fixe.

3.30 Principe général

Votre personnage n’est pas un avatar interchangeable.

Les événements qu’il vit doivent participer à son histoire.

Une blessure doit avoir un poids. Une décision doit pouvoir avoir une conséquence. Une mort définitive doit représenter l’aboutissement d’une véritable histoire RP.

Chapitre 4

Règlement des scènes

Toute scène sur Santos Legacy doit respecter les principes de cohérence, de fair-play et de possibilité de réaction.

L’objectif n’est pas de déterminer à l’avance qui doit gagner ou perdre, mais de permettre aux différents joueurs impliqués de construire une scène intéressante et crédible.

4.1 Début d’une scène

Une scène commence dès qu’une interaction RP significative débute entre plusieurs personnages.

Cela peut notamment être :

  • une confrontation ;
  • un contrôle ;
  • une poursuite ;
  • une négociation ;
  • une tentative d’enlèvement ;
  • un braquage ;
  • une altercation ;
  • une intervention policière ;
  • une scène médicale ;
  • une transaction importante.

À partir de ce moment, les joueurs doivent éviter toute action visant à esquiver artificiellement la scène.

4.2 Fin d’une scène

Une scène est considérée comme terminée lorsque ses principaux événements et conséquences immédiates ont été joués.

Quitter simplement une zone ne signifie pas nécessairement que toutes les conséquences RP disparaissent.

Certaines scènes peuvent avoir des répercussions plusieurs heures ou plusieurs jours plus tard.

4.3 Possibilité de réaction

Une action importante doit laisser une possibilité raisonnable de réaction aux autres joueurs lorsque la situation le permet.

Il est interdit d’utiliser volontairement les limites techniques du jeu pour empêcher toute réponse.

Cela ne signifie pas qu’un joueur doit systématiquement recevoir plusieurs avertissements avant chaque action.

Le contexte, la surprise, la préparation et la situation doivent toujours être pris en compte.

4.4 Escalade d’un conflit

Un conflit doit évoluer de manière cohérente.

Une dispute verbale ne doit pas automatiquement devenir une fusillade.

L’escalade peut passer par :

  • des avertissements ;
  • des menaces ;
  • des intimidations ;
  • des négociations ;
  • des représailles ;
  • des violences physiques ;
  • puis, lorsque le contexte le justifie réellement, l’utilisation d’armes.

Une arme à feu doit représenter une escalade importante.

4.5 Sommations

Une sommation est un avertissement clair permettant à une personne de comprendre ce qui lui est demandé et les conséquences possibles d’un refus.

Elle peut être donnée verbalement ou être rendue évidente par le contexte.

Une sommation doit rester :

  • compréhensible ;
  • réalisable ;
  • cohérente avec la situation.

Une phrase prononcée volontairement trop rapidement ou de manière incompréhensible ne constitue pas une sommation valable.

4.6 Une sommation n’est pas toujours obligatoire

Toutes les situations ne nécessitent pas automatiquement une sommation.

Dans certaines scènes, le contexte peut déjà représenter une menace parfaitement identifiable.

Exemple

Une personne qui ouvre volontairement le feu contre votre groupe ne nécessite pas nécessairement une nouvelle sommation avant que vous puissiez réagir.

À l’inverse, un simple désaccord ou une personne qui refuse de quitter un lieu ne justifie pas automatiquement une attaque létale.

4.7 Utilisation d’une arme

Sortir une arme représente une action sérieuse.

Un personnage ne devrait pas dégainer son arme à feu pour résoudre chaque conflit.

L’utilisation d’une arme doit être proportionnée :

  • à la menace ;
  • au contexte ;
  • aux risques ;
  • à l’histoire de la scène.

Les armes doivent servir le Roleplay et non remplacer systématiquement les interactions.

4.8 Fusillades

Une fusillade doit résulter d’un contexte RP cohérent.

Les joueurs doivent éviter de transformer volontairement chaque confrontation en échange de tirs.

Pendant une fusillade :

  • le Fear RP reste applicable ;
  • le Pain RP reste applicable ;
  • les mouvements irréalistes sont interdits ;
  • les blessures doivent être interprétées ;
  • les joueurs ne doivent pas chercher uniquement à maximiser leurs performances PvP.

Santos Legacy reste un serveur Roleplay, même pendant un combat.

4.9 Achèvement d’un joueur

Mettre volontairement fin à la vie d’un personnage déjà neutralisé doit disposer d’une justification RP sérieuse.

Le fait qu’une personne soit au sol ne donne pas automatiquement le droit de l’achever.

Les exécutions gratuites ou utilisées uniquement afin d’empêcher un joueur de participer à la suite d’une scène sont interdites.

Une exécution ne constitue pas automatiquement une Mort RP définitive.

4.10 Enlèvement

Un enlèvement doit disposer d’une raison RP identifiable.

Il ne doit pas devenir une activité répétée uniquement dans le but de provoquer des scènes.

Le joueur enlevé doit disposer d’un minimum de jeu et ne doit pas rester inutilement retenu pendant une durée excessive sans contenu RP.

Une personne enlevée doit respecter le Fear RP lorsque la menace est crédible.

4.11 Kidnapping d’un joueur sans motif

Enlever une personne totalement au hasard peut être accepté uniquement lorsqu’une scène crédible le justifie réellement.

Les enlèvements gratuits, répétitifs ou visant uniquement à chercher une victime sont interdits.

La prise d’un otage dans le cadre d’un braquage est régie par les règles spécifiques aux otages.

4.12 Prise d’otage

Une prise d’otage doit produire du jeu pour les différentes parties.

Un otage ne doit pas uniquement être considéré comme un objet servant à obtenir automatiquement un avantage.

Les demandes faites en échange d’un otage doivent rester raisonnables et cohérentes.

Les forces de l’ordre doivent, de leur côté, considérer sérieusement la vie des otages.

4.13 Faux otages

L’utilisation d’un ami ou d’un complice volontaire comme faux otage afin d’obtenir artificiellement un avantage lors d’un braquage est interdite sauf mécanique ou événement explicitement prévu par le serveur.

Un otage doit généralement être une personne réellement extérieure au groupe à l’origine de la scène.

4.14 Traitement des otages

Un otage doit recevoir une possibilité raisonnable d’interagir.

Il est interdit de :

  • l’humilier gratuitement pendant une durée excessive ;
  • le tuer uniquement parce que la scène devient moins avantageuse ;
  • prolonger inutilement sa détention sans contenu RP ;
  • lui imposer des actes dégradants sans justification et sans respecter les limites du serveur.

L’objectif d’une prise d’otage est de créer une scène, pas de supprimer le jeu d’un autre joueur.

4.15 Négociations

Lors d’une scène comportant une négociation, les différentes parties doivent laisser une marge de discussion raisonnable.

Une négociation ne signifie pas que toutes les demandes doivent être acceptées.

Les demandes doivent pouvoir être :

  • acceptées ;
  • refusées ;
  • modifiées ;
  • négociées.

Chaque partie doit être prête à faire évoluer la scène.

4.16 Demandes lors d’un braquage

Les demandes effectuées pendant un braquage doivent rester raisonnables.

Le serveur pourra fixer ultérieurement des limites spécifiques concernant :

  • les rançons ;
  • les véhicules ;
  • les moyens de fuite ;
  • les otages ;
  • les demandes faites aux forces de l’ordre.

Il est interdit de formuler volontairement des demandes impossibles uniquement afin de provoquer l’échec de la négociation.

4.17 Braquage

Un braquage doit être joué comme une véritable scène RP.

Il ne doit pas être considéré uniquement comme un moyen de générer rapidement de l’argent.

Les joueurs doivent prendre en compte :

  • la préparation ;
  • les risques ;
  • les témoins ;
  • la police ;
  • la fuite ;
  • les conséquences judiciaires ;
  • les blessures éventuelles.
4.18 Braquages en chaîne

Il est interdit d’enchaîner volontairement les braquages sans logique RP uniquement pour maximiser les gains.

Une activité criminelle répétitive doit conserver un minimum de cohérence et laisser de la place aux conséquences des actions précédentes.

4.19 Intervention extérieure

Un joueur ou groupe extérieur à une scène ne doit pas intervenir sans disposer d’une raison RP suffisante.

Voir une fusillade puis décider de rejoindre l’un des camps simplement parce que l’on connaît les joueurs concernés n’est pas suffisant.

Une intervention doit pouvoir être justifiée par les informations dont le personnage disposait réellement.

4.20 Renforts

L’appel de renforts doit passer par un moyen RP cohérent lorsque cela est possible.

Il est interdit de contacter discrètement des amis via Discord afin qu’ils viennent intervenir.

Une personne ne peut rejoindre une scène que si elle dispose d’une information RP lui permettant raisonnablement de connaître :

  • la situation ;
  • la localisation ;
  • la nécessité de son intervention.
4.21 Informations radio

Les informations transmises par radio doivent correspondre à ce que le personnage peut raisonnablement communiquer.

Un personnage en pleine fusillade ne doit pas être capable de transmettre calmement une quantité irréaliste d’informations extrêmement précises.

La communication doit tenir compte du contexte.

4.22 Fouille

Une fouille doit être justifiée par la scène.

Elle ne doit pas devenir un automatisme après chaque interaction.

Le joueur qui effectue une fouille doit laisser un minimum de temps à la scène et éviter les comportements visant uniquement à ouvrir immédiatement l’inventaire d’un autre joueur.

4.23 Vol sur un joueur

Le vol d’un autre joueur doit être cohérent avec la scène.

Il ne doit pas avoir pour seul objectif de dépouiller systématiquement chaque personne rencontrée.

Certains objets pourront être déclarés non-volables par les règles spécifiques ou les systèmes du serveur.

Le fair-play doit toujours être appliqué.

4.24 Dépouiller une personne inconsciente

Le fait qu’un personnage soit inconscient ne donne pas automatiquement le droit de lui prendre tout son inventaire.

La récupération d’objets doit rester cohérente avec :

  • le contexte ;
  • le temps disponible ;
  • les risques ;
  • la raison de la fouille.

Dépouiller systématiquement chaque joueur au sol est contraire à l’esprit du serveur.

4.25 Objets personnels

Certains objets directement liés à l’identité ou à des systèmes essentiels du personnage peuvent être protégés.

Cela peut notamment concerner :

  • certains documents officiels ;
  • des objets de métier spécifiques ;
  • des éléments indispensables au fonctionnement d’un script ;
  • certains objets obtenus dans le cadre d’un événement particulier.

Les listes spécifiques pourront être précisées séparément.

4.26 Forcer une transaction

Il est interdit d’utiliser une menace afin de forcer artificiellement un joueur à transférer des éléments majeurs de son patrimoine.

Cela comprend notamment :

  • une entreprise entière ;
  • une propriété importante ;
  • l’intégralité d’un compte bancaire ;
  • la totalité du patrimoine d’un personnage.

Les extorsions peuvent exister en RP, mais leurs conséquences doivent rester proportionnées.

4.27 Torture RP

Les scènes de torture doivent rester exceptionnelles et disposer d’une réelle justification RP.

Elles ne doivent jamais être utilisées uniquement afin de choquer ou d’humilier un joueur.

Les joueurs doivent respecter les limites personnelles lorsqu’une scène devient particulièrement sensible.

Aucune torture RP ne permet automatiquement d’obtenir toutes les informations détenues par un personnage.

4.28 Informations sous la contrainte

Lorsqu’un personnage est menacé ou torturé, il doit prendre en compte le Fear RP.

Cependant, cela ne signifie pas qu’il doit obligatoirement révéler instantanément toutes ses informations.

Il peut notamment :

  • mentir ;
  • négocier ;
  • donner une information partielle ;
  • tenter de protéger certaines personnes,

tant que son comportement reste cohérent avec la gravité de la menace.

4.29 Scènes sensibles

Les scènes comportant des éléments particulièrement sensibles doivent être abordées avec prudence.

Santos Legacy ne tolère pas les scènes dont l’objectif est uniquement de mettre volontairement un autre joueur mal à l’aise.

Le serveur pourra interdire totalement certaines catégories de contenu dans une section dédiée du règlement.

4.30 Scènes sexuelles

Aucune scène à caractère sexuel explicite ne doit être imposée à un joueur.

Toute interaction de nature intime doit respecter les limites des personnes concernées.

Les agressions sexuelles RP et contenus similaires peuvent être totalement interdits par Santos Legacy afin de préserver un environnement sain.

4.31 Humiliation RP

Une humiliation peut exister lorsqu’elle possède une justification RP, mais elle doit rester proportionnée.

Il est interdit d’utiliser une scène comme prétexte pour dégrader personnellement le joueur derrière le personnage.

Les humiliations longues, répétitives ou volontairement extrêmes pourront être interrompues par le staff.

4.32 Scène impliquant plusieurs groupes

Lorsqu’une scène implique plusieurs organisations, la lisibilité doit être privilégiée.

Les groupes ne doivent pas multiplier artificiellement les alliances de dernière minute uniquement afin d’obtenir un avantage numérique.

Les relations entre groupes doivent exister et avoir été construites en RP.

4.33 Supériorité numérique

Disposer d’un avantage numérique n’autorise pas à ignorer les règles de fair-play.

De même, être en infériorité numérique ne donne pas automatiquement le droit d’ignorer le Fear RP.

Chaque groupe doit adapter ses décisions aux risques de la situation.

4.34 Intervention après blessure

Un joueur grièvement blessé ou évacué ne doit pas revenir directement dans une scène afin d’aider son groupe.

Les joueurs encore présents doivent poursuivre sans lui lorsque la situation le justifie.

4.35 Crash pendant une scène

En cas de crash ou déconnexion involontaire, le joueur doit revenir sur le serveur dès que possible.

À son retour, la scène reprend dans une situation aussi proche que possible de celle précédant la déconnexion.

Un crash ne permet pas d’annuler les conséquences d’une scène.

4.36 Redémarrage serveur

Lorsqu’un redémarrage intervient pendant une scène importante, les joueurs doivent autant que possible reprendre la scène après le redémarrage.

Il est interdit d’utiliser un redémarrage connu à l’avance afin de lancer une action dans l’objectif d’échapper à ses conséquences.

4.37 Intervention du staff pendant une scène

Une scène ne doit être interrompue par le staff qu’en cas de nécessité.

Dans la majorité des situations, les joueurs doivent terminer leur scène avant de signaler une éventuelle infraction.

Lorsqu’un staff décide cependant de mettre une scène en pause, tous les joueurs concernés doivent arrêter leurs actions et suivre ses indications.

4.38 Litige après une scène

Après une scène contestée, les joueurs doivent éviter les règlements de compte directs.

Le litige doit être traité via les procédures prévues par le serveur.

Un désaccord sur une scène ne justifie pas :

  • des insultes HRP ;
  • du harcèlement ;
  • une vengeance HRP ;
  • une campagne contre un joueur ;
  • une multiplication de messages privés.
4.39 Enregistrement des scènes importantes

Pour les scènes à fort enjeu, il est fortement recommandé de disposer d’un enregistrement vidéo.

Cela concerne notamment :

  • les fusillades ;
  • les braquages ;
  • les conflits d’organisation ;
  • les scènes pouvant conduire à une Mort RP ;
  • les situations donnant lieu à un litige important.

L’absence d’enregistrement ne signifie pas automatiquement qu’un joueur est en tort, mais elle peut compliquer l’analyse d’un dossier.

4.40 Priorité au Roleplay

À tout moment, une scène doit être jouée en gardant à l’esprit une question simple :

« Est-ce que mon action améliore la scène ou est-ce que je cherche uniquement à obtenir un avantage ? »

Une mécanique, une règle ou une faille de formulation ne doit jamais être utilisée volontairement pour détruire une scène cohérente.

Principe fondamental des scènes

Donnez du jeu avant de chercher le résultat.

Une bonne scène ne se mesure pas uniquement à celui qui repart avec l’argent, qui échappe à la police ou qui gagne une fusillade.

Elle se mesure surtout à l’histoire qu’elle crée pour tous les joueurs impliqués.

Chapitre 5

Règlement Illégal

L’illégal sur Santos Legacy doit être considéré comme un véritable univers Roleplay.

Les activités criminelles ne doivent pas uniquement servir à générer de l’argent, accumuler des armes ou provoquer des affrontements.

Chaque groupe criminel doit chercher à développer :

  • une identité ;
  • une histoire ;
  • des relations ;
  • des activités ;
  • des rivalités ;
  • des alliances ;
  • une influence sur la ville.

L’objectif est de créer un milieu criminel vivant, évolutif et crédible.

5.1 Entrée dans l’illégal

Un personnage ne doit pas intégrer immédiatement le milieu criminel sans développement RP.

L’accès aux activités importantes doit se construire progressivement à travers :

  • des rencontres ;
  • des contacts ;
  • des services rendus ;
  • des relations de confiance ;
  • des opportunités RP.

Les informations liées aux réseaux criminels ne doivent pas circuler librement entre tous les joueurs.

5.2 Organisation criminelle

Une organisation reconnue doit disposer d’une véritable identité.

Cela peut notamment comprendre :

  • un nom ;
  • une histoire ;
  • une hiérarchie ;
  • des motivations ;
  • un style ;
  • des activités principales ;
  • une implantation dans la ville.

Une organisation ne doit pas uniquement exister afin de participer à des fusillades ou contrôler un maximum d’activités.

5.3 Gang

Un gang doit également posséder une identité et une présence RP identifiable.

Son développement peut notamment passer par :

  • un quartier ;
  • des relations locales ;
  • des activités criminelles ;
  • des rivalités ;
  • une culture de groupe ;
  • une influence sur certains secteurs.

La couleur d’un vêtement ou la possession d’un quartier ne suffit pas à créer du Roleplay de gang.

5.4 Recrutement

Le recrutement d’un membre doit être réalisé en RP.

Il est interdit de recruter automatiquement un joueur uniquement parce qu’il s’agit d’un ami HRP.

Le personnage doit avoir construit une relation crédible avec le groupe.

Les organisations sont encouragées à créer :

  • des périodes d’observation ;
  • des missions ;
  • des interactions ;
  • des épreuves RP ;

avant d’accorder une confiance importante à un nouveau membre.

5.5 Hiérarchie criminelle

La hiérarchie interne d’un groupe doit être respectée en RP.

Les grades ne doivent cependant pas devenir un moyen HRP permettant de contrôler ou humilier les autres joueurs.

Un chef de groupe possède une autorité RP sur son organisation, mais reste soumis au règlement de Santos Legacy.

5.6 Informations criminelles

Les informations sensibles concernant :

  • les laboratoires ;
  • les caches ;
  • les fournisseurs ;
  • les routes ;
  • les contacts ;
  • les activités ;
  • les identités ;

doivent être obtenues à travers du Roleplay.

Une information criminelle importante ne doit pas circuler simplement parce que plusieurs joueurs se connaissent HRP.

5.7 Activités criminelles

Les groupes sont encouragés à développer plusieurs formes de criminalité plutôt qu’à répéter constamment la même activité.

Cela peut notamment passer par :

  • trafic ;
  • recel ;
  • extorsion ;
  • cambriolages ;
  • braquages ;
  • courses clandestines ;
  • blanchiment ;
  • racket ;
  • contrebande ;
  • renseignement ;
  • influence économique.

Les activités réellement disponibles dépendront des systèmes présents sur Santos Legacy.

5.8 Drogues

Le trafic de drogues doit générer du Roleplay autour :

  • de la production ;
  • de l’approvisionnement ;
  • du transport ;
  • de la distribution ;
  • des intermédiaires ;
  • des territoires ;
  • des risques policiers.

Une organisation ne doit pas considérer automatiquement qu’une drogue lui appartient simplement parce qu’elle utilise régulièrement son système.

5.9 Découverte d’un réseau

La localisation d’un laboratoire, d’un point sensible ou d’un réseau criminel doit être découverte en RP.

Il est interdit d’utiliser :

  • un stream ;
  • une vidéo ;
  • une information HRP ;
  • une fuite Discord ;
  • une connaissance provenant d’un autre personnage

afin de découvrir un emplacement criminel.

5.10 Monopoles

Un groupe peut chercher à obtenir une position dominante sur une activité criminelle.

Cependant, un monopole doit être construit et défendu par le Roleplay.

Déclarer simplement :

« Cette drogue nous appartient. »

ne suffit pas.

Un monopole doit résulter d’une véritable influence sur :

  • l’approvisionnement ;
  • la production ;
  • les fournisseurs ;
  • la distribution ;
  • les relations criminelles.
5.11 Territoires

Un territoire représente une zone d’influence RP et non une propriété absolue de la carte.

Un groupe peut y posséder une présence importante, mais cela ne lui donne pas automatiquement le droit :

  • d’abattre toute personne présente ;
  • de fouiller chaque passant ;
  • d’interdire toute circulation ;
  • de considérer chaque intrusion comme une déclaration de guerre.

La réaction doit dépendre du contexte.

5.12 Revendication d’un territoire

Une revendication territoriale doit être construite à travers du RP.

Cela peut notamment passer par :

  • une présence régulière ;
  • des activités ;
  • des habitants ;
  • des commerces ;
  • des relations ;
  • des conflits ;
  • des accords avec d’autres groupes.

La carte ne doit pas être divisée artificiellement en zones que chaque organisation considère comme sa propriété permanente.

5.13 Tags et signes de territoire

Lorsqu’un système permet de marquer un territoire, son utilisation doit avoir une signification RP.

Détruire, recouvrir ou modifier le symbole d’un autre groupe peut représenter une provocation importante et doit être assumé comme tel.

5.14 Conflits entre groupes

Un conflit criminel doit toujours avoir une origine RP identifiable.

Il peut notamment provenir :

  • d’une dette ;
  • d’une trahison ;
  • d’une concurrence commerciale ;
  • d’un territoire ;
  • d’une attaque ;
  • d’une rupture d’accord ;
  • d’une information volée ;
  • d’un différend construit en jeu.

Les conflits HRP déguisés en conflits RP sont strictement interdits.

5.15 Progression d’un conflit

Un conflit important doit idéalement évoluer progressivement.

Les groupes sont encouragés à utiliser :

  • discussions ;
  • intimidations ;
  • avertissements ;
  • négociations ;
  • pressions économiques ;
  • vols ;
  • sabotages RP ;
  • enlèvements ;
  • démonstrations de force ;

avant de transformer systématiquement le conflit en guerre armée.

5.16 Guerre entre organisations

Une guerre doit représenter un événement majeur.

Elle ne doit pas être déclarée pour un désaccord mineur.

Une guerre importante pourra nécessiter une déclaration ou un suivi auprès du pôle Illégal afin de garantir :

  • la compréhension du contexte ;
  • le respect des règles ;
  • l’absence de conflit HRP ;
  • la cohérence des enjeux.
5.17 Une guerre n’est pas un Deathmatch permanent

Être officiellement en conflit avec un autre groupe ne signifie pas pouvoir tirer automatiquement sur chacun de ses membres à chaque rencontre.

Chaque interaction doit conserver un minimum de contexte.

Une guerre doit générer du Roleplay et non transformer certaines zones du serveur en Deathmatch permanent.

5.18 Fin d’un conflit

Tout conflit doit pouvoir avoir une issue.

Cela peut notamment passer par :

  • une négociation ;
  • une compensation ;
  • une dette ;
  • une perte de territoire ;
  • un accord ;
  • une trêve ;
  • une reddition ;
  • une médiation ;
  • une conséquence RP majeure.

Un conflit ne doit pas être entretenu éternellement uniquement afin de continuer les affrontements.

5.19 Alliances

Les alliances entre groupes doivent être construites en RP.

Une alliance ne doit pas apparaître uniquement au moment où un groupe a besoin de renforts.

Une relation crédible doit exister avant qu’un autre groupe intervienne dans un conflit important.

5.20 Méga-alliances

Les alliances regroupant une grande partie des organisations de la ville sont fortement déconseillées.

L’objectif est de préserver :

  • les rivalités ;
  • la diversité criminelle ;
  • les rapports de force ;
  • les opportunités de scènes.

Le pôle Illégal pourra intervenir lorsqu’une alliance devient manifestement nuisible à l’écosystème criminel du serveur.

5.21 Intervention d’un allié

Un groupe allié ne doit pas intervenir automatiquement dans toutes les scènes concernant un autre groupe.

Son intervention doit être justifiée par :

  • les accords existants ;
  • les informations disponibles ;
  • les enjeux de la scène.
5.22 Nombre de participants

Certaines activités criminelles pourront être limitées à un nombre maximum de participants.

Ces limites peuvent varier selon :

  • l’activité ;
  • le braquage ;
  • la disponibilité des forces de l’ordre ;
  • les systèmes du serveur.

Les règles spécifiques à chaque activité prévalent lorsqu’elles existent.

5.23 Reconnaissance des groupes

Une organisation ne doit pas automatiquement identifier l’appartenance d’un personnage simplement grâce à son apparence.

Une tenue, une couleur ou un véhicule peuvent constituer des indices mais ne donnent pas toujours une certitude absolue.

Le contexte doit être pris en considération.

5.24 Masques

Une personne masquée ne devient pas automatiquement identifiable grâce au nom affiché par le jeu.

Toute identification doit reposer sur des éléments obtenus en RP.

Les groupes ne doivent pas systématiquement utiliser la reconnaissance vocale comme justification absolue.

5.25 Armes

La possession d’une arme représente un risque important.

Les armes à feu ne doivent pas devenir un accessoire utilisé dans chaque interaction criminelle.

Sortir une arme doit pouvoir entraîner :

  • une escalade ;
  • une intervention policière ;
  • une arrestation ;
  • une saisie ;
  • des blessures ;
  • des conséquences judiciaires.
5.26 Armes lourdes

Les armes particulièrement puissantes doivent rester rares et cohérentes avec le niveau criminel du personnage ou de l’organisation.

Le fait qu’un joueur possède techniquement une arme ne signifie pas que son utilisation dans n’importe quelle scène est cohérente.

Des restrictions supplémentaires pourront être appliquées selon l’économie du serveur.

5.27 Vol d’armes

Le vol d’une arme doit respecter les règles générales de fouille et de dépouillement.

Il est interdit de chercher systématiquement à récupérer toutes les armes des personnes neutralisées simplement afin d’accumuler du matériel.

5.28 Racket et extorsion

Le racket est autorisé lorsqu’il génère du Roleplay.

Les demandes doivent rester proportionnées.

Une organisation ne doit pas exiger régulièrement des montants absurdes dans le but de rendre impossible le développement d’un autre joueur ou d’une entreprise.

5.29 Entreprises et illégal

Une organisation peut chercher à :

  • infiltrer ;
  • influencer ;
  • protéger ;
  • utiliser ;
  • faire pression sur

une entreprise légale.

Cependant, elle ne peut pas simplement décider qu’une entreprise lui appartient sans développement RP.

L’entreprise doit conserver une possibilité réelle de jouer et de réagir.

5.30 Blanchiment

Le blanchiment d’argent doit être traité comme une activité criminelle réelle et risquée.

Les joueurs doivent éviter d’utiliser mécaniquement un système de blanchiment sans aucune interaction ou précaution RP lorsque des alternatives existent.

Les réseaux de blanchiment sont encouragés à produire :

  • des contacts ;
  • des intermédiaires ;
  • des entreprises ;
  • des accords ;
  • des risques.
5.31 Corruption

La corruption peut créer d’excellentes histoires lorsqu’elle reste crédible.

Elle peut concerner certaines relations avec :

  • entreprises ;
  • employés ;
  • fonctionnaires ;
  • policiers ;
  • autres institutions,

selon les règles spécifiques des métiers concernés.

Une organisation ne peut pas forcer HRP un joueur à devenir corrompu.

5.32 Enlèvement d’un membre d’organisation

Enlever un membre d’un groupe rival doit avoir une véritable utilité RP.

L’objectif peut notamment être :

  • obtenir une information ;
  • envoyer un message ;
  • négocier ;
  • récupérer une dette ;
  • exercer une pression.

Les enlèvements successifs uniquement destinés à humilier le même groupe peuvent être considérés comme abusifs.

5.33 Enlèvement de membres des services publics

Enlever un policier, un médecin, un juge ou une autre personne occupant une fonction sensible doit représenter une action importante.

Une véritable justification RP est nécessaire.

Ces enlèvements ne doivent pas être utilisés comme solution facile à chaque problème criminel.

5.34 Fouille d’un membre rival

Une rivalité ne donne pas automatiquement le droit de fouiller chaque membre adverse rencontré.

La fouille doit être cohérente avec la scène en cours.

5.35 Vol de véhicules

Le vol de véhicule peut faire partie de l’illégal.

Cependant, voler systématiquement tous les véhicules rencontrés sans raison ou uniquement pour gêner les joueurs est interdit.

Le vol doit conserver une logique RP.

5.36 Véhicules criminels

Les organisations ne doivent pas transformer systématiquement chaque véhicule en véhicule jetable.

Les véhicules utilisés régulièrement peuvent devenir des éléments identifiables dans les enquêtes RP.

Changer constamment de véhicule uniquement afin d’éviter toute conséquence peut devenir incohérent.

5.37 Plaques et identification

Toute modification ou utilisation de plaques doit respecter les systèmes disponibles sur le serveur.

Les joueurs ne peuvent pas décider arbitrairement qu’un véhicule est impossible à identifier lorsqu’aucune mécanique RP ne le justifie.

5.38 Cambriolages et vols

Les cambriolages doivent conserver une logique criminelle.

Ils ne doivent pas devenir uniquement une boucle de farm.

Lorsqu’une scène implique directement d’autres joueurs, ceux-ci doivent disposer d’une possibilité raisonnable d’interaction.

5.39 Braquages

Les règles du Chapitre 4 restent applicables.

Un braquage doit notamment prendre en compte :

  • sa préparation ;
  • son niveau de risque ;
  • les otages ;
  • la police ;
  • la fuite ;
  • les conséquences.

Certaines activités pourront posséder leur propre règlement spécifique.

5.40 Braquages concurrents

Il est interdit de chercher volontairement à perturber un braquage effectué par un autre groupe uniquement pour voler sa récompense sans contexte préalable.

Toute intervention criminelle extérieure doit disposer d’une véritable justification RP.

5.41 Vol entre organisations

Les organisations peuvent se voler ou se nuire dans le cadre d’un conflit cohérent.

Cependant, l’objectif ne doit pas être de détruire entièrement plusieurs semaines ou mois de progression d’un groupe en une seule scène sans possibilité de réaction.

5.42 Destruction économique d’un groupe

Aucun groupe ne doit chercher uniquement à empêcher totalement un autre groupe de jouer.

Même en guerre, les actions doivent laisser des possibilités de reconstruction et de développement RP.

L’objectif est de créer des conséquences, pas de supprimer un groupe du serveur par épuisement HRP.

5.43 Dissolution d’une organisation

Une organisation peut disparaître à la suite :

  • de décisions RP ;
  • d’une dissolution volontaire ;
  • d’événements majeurs ;
  • de sanctions exceptionnelles ;
  • d’une décision de la direction lorsque son fonctionnement devient incompatible avec le serveur.

Une organisation rivale ne peut pas décider seule de supprimer définitivement un groupe.

5.44 Mort RP dans l’illégal

Les activités criminelles exposent naturellement les personnages à davantage de risques.

Cependant, appartenir à une organisation ne signifie pas accepter automatiquement une Mort RP décidée unilatéralement par un autre groupe.

Les règles du Chapitre 3 restent entièrement applicables.

5.45 Trahison

Une trahison peut avoir des conséquences importantes.

Un membre qui :

  • transmet des informations ;
  • vole son organisation ;
  • travaille pour un rival ;
  • collabore secrètement avec les autorités

doit accepter que ces actions puissent provoquer des conséquences RP sérieuses.

Celles-ci doivent toutefois rester conformes au règlement général et aux règles concernant la Mort RP.

5.46 Quitter une organisation

Quitter une organisation doit être joué en RP lorsque le personnage y occupait une place importante.

Le groupe peut réagir à ce départ selon :

  • les connaissances du personnage ;
  • son rôle ;
  • les circonstances ;
  • les relations internes.

Quitter une organisation ne donne cependant pas automatiquement le droit de tuer définitivement le personnage.

5.47 Informations après un départ

Un ancien membre conserve les connaissances réellement acquises par son personnage.

Cependant, le joueur doit rester fair-play et ne pas transformer immédiatement toutes ses anciennes connaissances en outil permettant de détruire son précédent groupe.

Les circonstances du départ doivent guider son comportement.

5.48 Collaboration avec la police

Un criminel peut décider de collaborer avec les autorités lorsque cela correspond à son histoire.

Cette décision peut entraîner de lourdes conséquences RP.

Les groupes concernés doivent cependant continuer à respecter l’ensemble du règlement lors de leurs représailles.

5.49 Relations avec le pôle Illégal

Le Pôle Illégal n’a pas vocation à diriger les organisations à leur place.

Son rôle est notamment de :

  • suivre l’écosystème criminel ;
  • accompagner les projets ;
  • arbitrer certaines situations ;
  • prévenir les conflits HRP ;
  • assurer l’équilibre entre les groupes ;
  • garantir le respect du règlement.

Les organisations restent libres de construire leur propre histoire dans ce cadre.

5.50 Projets criminels

Les joueurs sont encouragés à proposer des projets originaux.

Une organisation ne doit pas se limiter aux systèmes disponibles dans les scripts.

Les joueurs peuvent créer du Roleplay autour :

  • d’un réseau de renseignement ;
  • d’une entreprise écran ;
  • d’un système de dette ;
  • d’événements clandestins ;
  • de paris ;
  • de courses illégales ;
  • de contrebande ;
  • de corruption ;
  • d’influence politique ou économique,

dans le respect des règles et des systèmes du serveur.

5.51 Fair-play criminel

Être criminel ne dispense jamais des règles de fair-play.

Il est particulièrement attendu des groupes reconnus qu’ils contribuent à la qualité générale du serveur.

Une organisation importante doit être capable :

  • de gagner ;
  • de perdre ;
  • de négocier ;
  • de subir des conséquences ;
  • de créer du jeu pour les autres.
5.52 Principe fondamental de l’illégal

Le pouvoir d’une organisation ne doit pas uniquement être mesuré au nombre d’armes, de membres ou de fusillades remportées.

Une organisation influente est avant tout une organisation capable de construire : des relations, des réseaux, des secrets, des alliances, des rivalités et une histoire.

Sur Santos Legacy, l’illégal doit produire du Roleplay avant de produire du PvP.

Chapitre 6

Règlement Légal

Les métiers légaux sur Santos Legacy doivent être considérés comme de véritables rôles RP et non comme de simples fonctions techniques.

Les joueurs occupant une fonction publique, judiciaire, médicale ou économique importante doivent agir avec :

  • cohérence ;
  • professionnalisme ;
  • mesure ;
  • fair-play ;
  • respect du RP des autres joueurs.

La position occupée par un personnage ne donne jamais tous les droits.

6.1 Responsabilité des métiers légaux

Les métiers légaux ont une responsabilité particulière dans l’équilibre du serveur.

Ils doivent contribuer à créer :

  • des scènes ;
  • des enquêtes ;
  • des interactions ;
  • des opportunités ;
  • des conséquences ;
  • du développement RP.

Une institution ne doit jamais devenir un simple outil de domination.

6.2 LSPD

Les membres du LSPD doivent agir dans le cadre de leurs fonctions et respecter les procédures définies par leur hiérarchie.

Le comportement attendu doit rester cohérent avec :

  • leur grade ;
  • leur formation ;
  • leur expérience ;
  • leur fonction ;
  • la situation rencontrée.

Un policier ne doit pas agir comme un justicier indépendant.

6.3 Abus de fonction

Il est interdit d’utiliser une fonction légale pour obtenir un avantage personnel injustifié.

Cela peut notamment concerner :

  • l’utilisation d’informations confidentielles ;
  • l’accès abusif à des bases de données ;
  • les fouilles sans justification ;
  • les saisies injustifiées ;
  • les arrestations arbitraires ;
  • les menaces liées à une fonction ;
  • l’utilisation d’un véhicule ou matériel de service à des fins personnelles.
6.4 Contrôles

Tout contrôle doit avoir une justification RP cohérente.

Un policier ne doit pas contrôler systématiquement un joueur simplement parce qu’il le considère comme suspect HRP.

Un contrôle peut notamment être justifié par :

  • une infraction ;
  • un comportement suspect ;
  • une enquête ;
  • une description ;
  • une zone particulière ;
  • une situation de danger.
6.5 Fouilles

Une fouille doit être justifiée par la situation ou les procédures légales du serveur.

Une fouille ne doit pas être utilisée comme moyen automatique de chercher une infraction.

Le joueur fouillé doit être informé de la situation lorsque cela est cohérent.

6.6 Arrestations

Une arrestation doit reposer sur un motif identifiable.

Le joueur concerné doit pouvoir comprendre pourquoi son personnage est arrêté.

Une arrestation ne doit pas être prolongée inutilement uniquement afin de punir un joueur HRP.

6.7 Usage de la force

L’usage de la force doit rester proportionné à la menace.

Les forces de l’ordre doivent privilégier lorsque cela est possible :

  1. le dialogue ;
  2. les ordres ;
  3. les moyens de contrainte ;
  4. les moyens non létaux ;
  5. les moyens létaux lorsque la menace le justifie réellement.
6.8 Usage des armes à feu

Un policier ne doit pas utiliser son arme à feu comme réponse automatique.

L’usage d’une arme létale doit correspondre à une menace grave.

Une fuite simple ne justifie pas automatiquement des tirs.

6.9 Poursuites

Les poursuites doivent rester cohérentes.

Les forces de l’ordre comme les suspects doivent tenir compte :

  • de la circulation ;
  • des piétons ;
  • de la météo ;
  • du terrain ;
  • de la vitesse ;
  • des risques.

Le but n’est pas de gagner à tout prix.

6.10 PIT

Une manœuvre PIT doit être utilisée de manière proportionnée.

Elle ne doit pas être tentée dans des conditions manifestement dangereuses sans nécessité.

Son utilisation doit notamment prendre en compte :

  • la vitesse ;
  • la zone ;
  • le trafic ;
  • le type de véhicule ;
  • le risque pour les civils.
6.11 Barrages

Un barrage doit être installé de manière cohérente.

Les barrages totalement irréalistes, impossibles à éviter ou destinés uniquement à provoquer un accident sont interdits.

6.12 Herse et dispositifs d’interception

Les herses et moyens similaires doivent être utilisés de manière réfléchie.

Ils ne doivent pas être placés uniquement pour exploiter les limites du jeu.

6.13 Négociations policières

Lors d’un braquage ou d’une prise d’otage, les forces de l’ordre doivent prendre les négociations au sérieux.

La priorité doit être de créer une scène crédible tout en protégeant les vies.

Toutes les demandes ne doivent pas être acceptées, mais elles doivent être réellement considérées.

6.14 Assaut

Un assaut doit représenter une décision importante.

Il doit être justifié par :

  • le danger ;
  • l’échec des négociations ;
  • une menace immédiate ;
  • une évolution grave de la situation.

L’assaut ne doit pas devenir la solution automatique.

6.15 Otages

La vie d’un otage doit être prise en compte.

Les forces de l’ordre ne doivent pas ignorer volontairement un risque évident pour l’otage uniquement pour gagner une scène.

6.16 Renforts policiers

Les renforts doivent être appelés de manière RP.

La présence policière doit rester proportionnée à la scène lorsque cela est possible.

Une intervention mineure ne nécessite pas automatiquement la mobilisation de toute la police.

6.17 Hélicoptères et unités spéciales

Les moyens spécialisés doivent être utilisés pour des situations adaptées.

Ils ne doivent pas être déployés systématiquement pour des infractions mineures.

6.18 Base de données policière

Les informations contenues dans les systèmes policiers sont considérées comme des informations RP confidentielles.

Il est interdit de les consulter :

  • par curiosité ;
  • pour aider un ami ;
  • pour anticiper une scène ;
  • pour transmettre des informations à un tiers sans justification.
6.19 Casier judiciaire

Le casier judiciaire doit être utilisé uniquement dans un contexte RP cohérent.

Les informations qui y figurent ne doivent pas automatiquement définir tout le comportement futur d’un personnage.

6.20 Enquêtes

Une enquête doit être construite à partir d’éléments obtenus en RP.

Les enquêteurs doivent pouvoir expliquer l’origine de leurs informations.

Il est interdit de construire une enquête à partir :

  • d’un stream ;
  • d’une conversation HRP ;
  • d’un autre personnage ;
  • d’informations obtenues hors jeu.
6.21 Preuves

Une preuve doit être obtenue de manière RP.

Elle peut notamment provenir de :

  • témoignages ;
  • vidéos ;
  • photographies ;
  • caméras RP ;
  • saisies ;
  • documents ;
  • analyses ;
  • surveillance.

Le simple soupçon d’un policier ne constitue pas automatiquement une preuve.

6.22 Caméras

Les caméras doivent respecter le Mass RP et les systèmes définis par le serveur.

Elles ne doivent pas être invoquées de manière magique uniquement lorsqu’elles arrangent une scène.

Le serveur peut définir les lieux où des caméras sont considérées comme présentes.

6.23 Perquisitions

Une perquisition doit être justifiée conformément aux procédures du serveur.

Elle doit reposer sur un dossier ou des éléments suffisants lorsque cela est requis.

La perquisition d’une propriété ne doit pas devenir une simple méthode d’exploration.

6.24 Saisies

Les saisies doivent rester proportionnées.

Les forces de l’ordre ne doivent pas saisir des éléments sans lien avec l’infraction ou la procédure en cours lorsqu’aucune justification ne l’exige.

6.25 Garde à vue

Une garde à vue doit être utilisée pour faire du RP.

Elle ne doit pas consister à laisser un joueur seul pendant une longue durée sans interaction.

Lorsque cela est possible, elle doit permettre :

  • interrogatoire ;
  • avocat ;
  • enquête ;
  • négociation ;
  • décision judiciaire.
6.26 Interrogatoires

Un interrogatoire doit laisser au suspect une marge de réaction.

Un suspect peut :

  • mentir ;
  • garder le silence ;
  • négocier ;
  • coopérer ;
  • refuser de répondre,

dans les limites des lois RP du serveur.

6.27 Avocats

Les avocats doivent disposer d’une vraie place dans le système judiciaire.

Ils ne doivent pas uniquement servir à réduire mécaniquement les peines.

Ils peuvent :

  • conseiller ;
  • négocier ;
  • défendre ;
  • contester ;
  • accompagner une procédure.
6.28 Justice

La justice doit rester indépendante dans la mesure du possible.

Un juge ou procureur ne doit pas utiliser sa fonction pour régler un conflit personnel.

Les décisions doivent être fondées sur :

  • les faits ;
  • les preuves ;
  • les procédures ;
  • les lois RP.
6.29 Procès

Les procès importants doivent créer du RP pour les différentes parties.

Ils peuvent inclure :

  • accusation ;
  • défense ;
  • témoignages ;
  • preuves ;
  • arguments ;
  • décision.

Un procès ne doit pas être joué comme une simple formalité lorsque l’affaire présente un véritable enjeu.

6.30 Peines

Les peines doivent rester proportionnées.

Le but du système judiciaire n’est pas d’empêcher un joueur de jouer pendant une durée excessive.

Les sanctions RP doivent chercher un équilibre entre :

  • conséquence ;
  • réalisme ;
  • intérêt de la scène ;
  • jouabilité.
6.31 Prison

Une peine de prison doit pouvoir générer du RP lorsque cela est possible.

Les longues peines doivent rester exceptionnelles et justifiées.

Le serveur peut utiliser des peines alternatives pour favoriser le Roleplay.

6.32 Travaux d’intérêt général

Les travaux d’intérêt général peuvent être utilisés comme alternative à certaines sanctions.

Ils doivent rester cohérents avec la gravité de l’infraction.

6.33 Corruption policière

La corruption d’un membre des forces de l’ordre ne doit jamais être banalisée.

Elle doit être construite sur le long terme et peut nécessiter une validation selon le niveau de corruption envisagé.

Une corruption importante peut entraîner :

  • enquête interne ;
  • révocation ;
  • arrestation ;
  • conséquences judiciaires ;
  • Mort RP dans des cas exceptionnels validés.
6.34 Fuite d’informations

Transmettre volontairement des informations confidentielles à un criminel constitue une action RP majeure.

Elle doit être assumée comme telle et peut provoquer des conséquences importantes.

6.35 EMS

Les EMS doivent privilégier le RP médical et humain.

Ils doivent éviter de considérer chaque intervention comme une simple mécanique de réanimation.

6.36 Prise en charge médicale

Un patient doit recevoir une prise en charge cohérente avec son état.

Les EMS peuvent demander des informations sur :

  • les blessures ;
  • les circonstances ;
  • les symptômes ;
  • l’historique médical RP.
6.37 Réanimation

La réanimation ne doit pas annuler automatiquement les conséquences d’une scène.

Un personnage réanimé peut rester blessé et devoir être hospitalisé.

6.38 Refus de soins

Un personnage peut refuser certains soins si son état lui permet raisonnablement de prendre cette décision.

Un joueur ne peut cependant pas utiliser ce refus uniquement pour contourner les conséquences d’une blessure grave.

6.39 Secret médical

Les informations médicales d’un personnage doivent être traitées avec discrétion.

Un EMS ne doit pas transmettre librement des informations sensibles sans justification RP.

6.40 EMS et scènes criminelles

Les EMS ne doivent pas favoriser volontairement un groupe.

Ils doivent intervenir avec neutralité lorsque cela est possible.

Les criminels et forces de l’ordre doivent respecter le rôle médical des EMS.

6.41 Enlèvement d’un EMS

L’enlèvement d’un EMS doit être exceptionnel et justifié par un véritable contexte RP.

Les EMS ne doivent pas être considérés comme des otages faciles uniquement parce qu’ils sont accessibles.

6.42 Neutralité médicale

Un EMS en service ne doit pas devenir un participant actif à un conflit.

Son rôle principal reste médical.

6.43 Gouvernement

Les membres du gouvernement disposent d’une influence importante et doivent l’utiliser avec mesure.

Les décisions gouvernementales doivent viser à créer du RP pour la ville et non uniquement favoriser certains joueurs ou groupes.

6.44 Pouvoir politique

Le pouvoir politique ne doit pas être utilisé pour neutraliser arbitrairement une organisation, une entreprise ou un individu.

Les décisions importantes doivent reposer sur une justification RP identifiable.

6.45 Lois

Les lois RP doivent être accessibles et compréhensibles.

Un joueur ne doit pas être sanctionné pour une règle juridique impossible à connaître ou totalement incohérente.

6.46 Création de nouvelles lois

Les nouvelles lois doivent répondre à un besoin RP réel.

Le gouvernement ne doit pas créer des textes uniquement pour cibler un personnage ou un groupe particulier.

6.47 Corruption politique

La corruption politique peut être autorisée lorsqu’elle est construite en RP.

Les formes importantes de corruption peuvent nécessiter une validation afin de préserver l’équilibre du serveur.

6.48 Entreprises

Une entreprise doit être considérée comme un projet RP.

Son objectif ne doit pas être uniquement économique.

Les entreprises doivent encourager :

  • l’emploi ;
  • les interactions ;
  • les événements ;
  • les partenariats ;
  • la concurrence ;
  • le développement de la ville.
6.49 Gestion d’entreprise

Un patron est responsable du développement RP de son entreprise.

Il ne doit pas utiliser son statut uniquement pour accumuler de l’argent.

Une entreprise inactive pendant une longue période peut être réattribuée selon les règles du serveur.

6.50 Recrutement en entreprise

Le recrutement doit se faire principalement en RP.

Le favoritisme HRP systématique est déconseillé.

Les entreprises doivent laisser une chance raisonnable aux nouveaux joueurs de créer des opportunités.

6.51 Argent d’entreprise

L’argent d’une société appartient à la société.

Un patron ne doit pas traiter le compte d’entreprise comme son compte bancaire personnel.

Les retraits importants doivent pouvoir être justifiés.

6.52 Détournement de fonds

Un détournement de fonds peut constituer une intrigue RP lorsqu’il est correctement construit.

Il ne doit pas être utilisé uniquement pour vider une entreprise avant de quitter le serveur ou le métier.

6.53 Prix et économie

Les entreprises doivent respecter l’économie générale du serveur.

Les prix ne doivent pas être volontairement manipulés afin de :

  • détruire une concurrence ;
  • exploiter un bug ;
  • transférer artificiellement de l’argent ;
  • contourner un système économique.
6.54 Monopole légal

Une entreprise peut devenir dominante grâce à son activité.

Cependant, elle ne doit pas utiliser des procédés HRP ou abusifs pour empêcher toute concurrence.

6.55 Employés en service

Lorsqu’un joueur se considère en service, il doit adopter un comportement cohérent avec sa fonction.

Utiliser les outils d’un métier pour des activités totalement étrangères à celui-ci peut être sanctionné.

6.56 Véhicules de service

Les véhicules de service doivent être utilisés principalement dans le cadre du métier correspondant.

Ils ne doivent pas être utilisés comme véhicules personnels sans justification.

6.57 Matériel de service

Le matériel obtenu grâce à un métier reste lié à cette fonction.

Il est interdit de détourner ou distribuer massivement :

  • armes ;
  • équipements ;
  • médicaments ;
  • outils ;
  • objets professionnels,

sans justification RP.

6.58 Démission

Une démission doit être cohérente avec la situation du personnage.

Un joueur ne doit pas utiliser une démission uniquement pour contourner immédiatement les conséquences d’une enquête interne ou d’une sanction RP.

6.59 Double activité

Certaines fonctions peuvent être incompatibles entre elles.

Le serveur peut interdire à un même personnage de cumuler certains rôles lorsque cela crée un conflit d’intérêts.

6.60 Conflit d’intérêts

Un personnage occupant une fonction importante doit éviter de traiter personnellement une affaire lorsqu’il est directement impliqué.

Cela peut concerner :

  • un policier enquêtant sur un proche ;
  • un juge impliqué dans une affaire personnelle ;
  • un responsable public favorisant sa propre entreprise.
6.61 Relations avec l’illégal

Les métiers légaux peuvent développer des relations complexes avec le milieu criminel.

Cependant, ces relations doivent rester cohérentes avec :

  • le métier ;
  • le personnage ;
  • les risques ;
  • les conséquences.

Un fonctionnaire ne devient pas criminel uniquement parce qu’un joueur lui propose de l’argent.

6.62 Informations privilégiées

Les informations obtenues grâce à une fonction ne doivent pas être utilisées pour enrichir ou aider artificiellement :

  • un ami ;
  • une organisation ;
  • un autre personnage ;
  • une entreprise personnelle.
6.63 Licenciements

Un licenciement doit avoir une justification RP ou professionnelle.

Les licenciements destinés uniquement à régler un conflit HRP sont interdits.

6.64 Sanctions internes

Les sanctions internes peuvent être utilisées pour créer du RP.

Elles doivent rester proportionnées et ne doivent pas être utilisées comme moyen de harcèlement.

6.65 Hiérarchie

La hiérarchie doit être respectée dans les métiers structurés.

Cela ne signifie cependant pas qu’un supérieur peut exiger n’importe quoi.

Chaque ordre doit rester compatible avec le règlement et le rôle de l’institution.

6.66 Formation

Les métiers importants sont encouragés à mettre en place des formations RP.

La progression dans une institution doit idéalement reposer sur :

  • l’expérience ;
  • les compétences ;
  • l’implication ;
  • le comportement.
6.67 Promotions

Les promotions doivent rester cohérentes.

Un nouveau joueur ne devrait pas accéder immédiatement à une fonction extrêmement importante sans développement suffisant.

6.68 Favoritisme

Le favoritisme HRP ne doit pas déterminer systématiquement :

  • les promotions ;
  • les recrutements ;
  • les sanctions ;
  • les avantages ;
  • l’accès à certaines fonctions.

Les décisions doivent rester défendables en RP.

6.69 Institutions et scènes

Une institution ne doit jamais utiliser sa puissance pour fermer toutes les possibilités de jeu.

Même lorsqu’elle dispose légalement de l’avantage, elle doit chercher à produire du RP.

6.70 Principe fondamental du légal

Le pouvoir institutionnel doit toujours être accompagné de responsabilité.

Un policier, un juge, un médecin, un responsable politique ou un chef d’entreprise ne doit pas chercher uniquement à imposer son autorité.

Sur Santos Legacy, les métiers légaux doivent créer : des services, des enquêtes, des opportunités, des décisions et des conséquences.

Le légal ne doit pas étouffer le Roleplay.

Il doit lui donner une structure.

Chapitre 7

Véhicules, conduite et poursuites

L’utilisation des véhicules sur Santos Legacy doit rester cohérente avec un environnement Roleplay.

Les performances de GTA V ne doivent pas être utilisées comme excuse pour adopter une conduite totalement irréaliste.

Chaque joueur doit tenir compte :

  • du véhicule utilisé ;
  • de la route ;
  • du terrain ;
  • de la vitesse ;
  • de la circulation ;
  • des blessures ;
  • du contexte de la scène.
7.1 Conduite RP

La conduite doit rester globalement réaliste.

Il n’est pas demandé aux joueurs de respecter chaque limitation de vitesse au kilomètre près, mais les comportements totalement incohérents sont interdits.

Cela comprend notamment :

  • rouler constamment à vitesse maximale en ville ;
  • traverser systématiquement les trottoirs ;
  • prendre chaque virage comme sur un circuit ;
  • ignorer volontairement la circulation ;
  • utiliser les autres véhicules comme obstacles jetables.
7.2 Code de la route

Le Code de la route existe en RP.

Un joueur peut évidemment commettre des infractions, mais celles-ci peuvent entraîner des conséquences policières.

Une infraction volontaire ne constitue pas en elle-même une violation du règlement serveur.

7.3 Excès de vitesse

Un excès de vitesse peut être cohérent selon la situation.

En revanche, rouler continuellement à des vitesses extrêmes sans aucune raison peut être considéré comme incohérent.

Le contexte doit toujours être pris en compte.

7.4 Feux rouges et intersections

Les joueurs ne sont pas obligés de s’arrêter systématiquement à chaque feu rouge dans toutes les situations.

Cependant, traverser une intersection à pleine vitesse sans tenir compte du trafic reste incohérent.

7.5 Conduite dangereuse

La conduite dangereuse doit avoir une justification lorsqu’elle devient extrême.

Une poursuite, une urgence ou une fuite peuvent justifier davantage de risques.

Une simple balade ne le justifie pas.

7.6 Accidents

Un accident important doit être interprété.

Après un choc violent, le joueur doit tenir compte :

  • des blessures ;
  • de l’état du véhicule ;
  • de la violence de l’impact ;
  • de la possibilité réelle de continuer à conduire.
7.7 Tonneaux

Après plusieurs tonneaux ou un accident extrêmement violent, repartir immédiatement comme si rien ne s’était passé est interdit.

Selon la gravité de l’accident, le joueur devra :

  • ralentir ;
  • s’arrêter ;
  • sortir du véhicule ;
  • demander une assistance ;
  • interpréter des blessures.
7.8 Véhicule endommagé

Un véhicule fortement endommagé doit être considéré comme tel.

Il est interdit de continuer volontairement à utiliser un véhicule dans des conditions manifestement irréalistes simplement parce que le moteur fonctionne encore techniquement.

7.9 Véhicule retourné

Lorsqu’un véhicule est retourné, les joueurs ne doivent pas utiliser une mécanique ou une manipulation irréaliste pour le remettre instantanément sur ses roues.

Une intervention cohérente doit être privilégiée.

7.10 Réparations

Une réparation doit respecter les systèmes et métiers prévus sur le serveur.

Un joueur ne doit pas réparer miraculeusement un véhicule lourdement endommagé au milieu d’une scène sans justification.

7.11 Véhicules adaptés au terrain

Le véhicule utilisé doit être adapté au terrain.

Un véhicule sportif classique ne doit pas être utilisé comme un véhicule tout-terrain sans conséquence.

7.12 Off-road

Le hors-piste doit rester cohérent.

Un SUV, un 4x4 ou un véhicule adapté peut emprunter certains chemins difficiles.

Une supercar ne doit pas traverser montagnes, rochers et forêts à pleine vitesse comme si elle roulait sur autoroute.

7.13 Sauts

Les sauts volontaires avec un véhicule doivent rester exceptionnels.

Utiliser régulièrement des escaliers, falaises, rampes ou reliefs pour gagner du temps ou échapper à une poursuite est interdit lorsque cela devient irréaliste.

7.14 Raccourcis irréalistes

Il est interdit d’utiliser constamment :

  • voies ferrées ;
  • escaliers ;
  • plages ;
  • montagnes ;
  • passages piétons ;
  • zones impraticables

comme raccourcis simplement afin d’obtenir un avantage.

7.15 Conduite sur trottoir

Rouler brièvement sur un trottoir peut arriver dans certaines situations.

L’utiliser volontairement comme voie de circulation principale est interdit.

Le Mass RP doit être pris en compte.

7.16 Mass RP et circulation

Même lorsque peu de PNJ sont visibles, les routes et zones urbaines doivent être considérées comme fréquentées.

Les joueurs doivent adapter leur conduite à l’environnement.

7.17 Véhicules volés

Le vol de véhicule doit respecter les règles RP générales.

Un joueur ne doit pas voler chaque véhicule disponible uniquement pour gagner du temps.

7.18 Véhicules PNJ

Le vol d’un véhicule PNJ doit rester cohérent avec la situation.

Il ne doit pas être utilisé comme solution systématique dès qu’un joueur perd son propre véhicule.

7.19 Véhicule personnel

Un véhicule personnel constitue un élément RP du personnage.

Les joueurs doivent éviter de considérer tous leurs véhicules comme totalement interchangeables.

7.20 Reconnaissance d’un véhicule

Un véhicule régulièrement utilisé peut devenir identifiable en RP.

Sa couleur, son modèle, ses modifications ou sa plaque peuvent servir d’indices.

7.21 Plaques d’immatriculation

Une plaque d’immatriculation représente une information RP.

Elle ne doit pas être ignorée lorsqu’elle est clairement visible.

Les systèmes permettant de modifier ou masquer une plaque doivent être utilisés conformément aux mécaniques du serveur.

7.22 Véhicules sans plaque

Un joueur ne peut pas décider arbitrairement que son véhicule ne possède aucune plaque simplement parce que cela l’arrange.

Une absence ou modification doit être liée à un système prévu.

7.23 Véhicule de service

Les véhicules professionnels doivent rester liés à leur fonction.

Ils ne doivent pas être utilisés comme véhicules personnels sans justification.

7.24 Véhicules d’urgence

Les véhicules d’urgence doivent être utilisés avec prudence.

Les sirènes et gyrophares ne donnent pas tous les droits.

Le conducteur doit continuer à tenir compte :

  • des intersections ;
  • du trafic ;
  • des piétons ;
  • des risques.
7.25 Véhicules de police

Les véhicules de police doivent être utilisés en fonction de leur rôle.

Une unité légère ne doit pas automatiquement être utilisée comme véhicule tout-terrain ou bélier.

7.26 Ambulances

Une ambulance ne doit pas être utilisée comme véhicule de course ou véhicule de combat.

Son utilisation doit rester liée à son rôle médical.

7.27 Poursuites

Une poursuite doit rester une scène RP avant d’être une compétition mécanique.

Les deux parties doivent tenir compte :

  • de leur véhicule ;
  • de leur état ;
  • des conditions de route ;
  • du danger ;
  • de la circulation.
7.28 Conducteur poursuivi

Un conducteur poursuivi peut prendre des risques.

Cependant, il ne doit pas adopter une conduite totalement suicidaire uniquement parce qu’il souhaite absolument échapper à la police.

7.29 Forces de l’ordre en poursuite

Les forces de l’ordre doivent également adopter une conduite cohérente.

La volonté d’arrêter un suspect ne justifie pas de mettre constamment en danger l’ensemble de la ville.

7.30 Changement de véhicule pendant une poursuite

Changer de véhicule peut être autorisé si la scène le permet.

Cependant, les changements répétés uniquement destinés à exploiter les mécaniques du jeu peuvent être considérés comme abusifs.

7.31 Garage pendant une poursuite

Il est interdit de ranger volontairement un véhicule dans un garage pendant une poursuite active afin de le faire disparaître.

La scène doit être terminée avant d’utiliser un garage comme moyen de sécurisation.

7.32 Déconnexion pendant une poursuite

Une déconnexion volontaire pendant une poursuite est considérée comme du Combat Logging.

En cas de crash, le joueur doit revenir dès que possible.

7.33 PIT

La manœuvre PIT doit être utilisée avec discernement.

Elle doit prendre en compte :

  • la vitesse ;
  • la route ;
  • le trafic ;
  • les piétons ;
  • la dangerosité du suspect ;
  • le risque de blessures graves.
7.34 PIT à haute vitesse

Une manœuvre PIT à très haute vitesse peut représenter un danger extrêmement important.

Elle doit être évitée lorsqu’elle provoquerait presque nécessairement un accident grave sans nécessité suffisante.

7.35 PIT avec véhicules lourds

Les véhicules lourds ou très imposants doivent être pris en compte.

Une petite voiture de police ne doit pas effectuer volontairement une manœuvre totalement irréaliste contre un véhicule beaucoup plus massif.

7.36 PIT par les criminels

Les criminels peuvent également utiliser leur véhicule pour tenter de bloquer ou gêner un poursuivant lorsque cela reste cohérent.

Cependant, transformer volontairement le véhicule en arme principale peut relever du VDM.

7.37 Car Ram

Le Car Ram consiste à utiliser volontairement son véhicule pour percuter de manière répétée un autre véhicule afin de provoquer artificiellement sa destruction ou son immobilisation.

Le Car Ram abusif est interdit.

7.38 Blocage d’un véhicule

Bloquer un véhicule peut être cohérent dans certaines situations.

Cependant, enfermer totalement un joueur sans possibilité réaliste uniquement grâce aux limites du jeu peut être considéré comme du Powergaming.

7.39 Roadblock

Un barrage routier peut être utilisé lorsqu’il est cohérent et laisse une possibilité raisonnable de réaction.

Un barrage impossible à voir ou conçu uniquement pour provoquer un crash majeur peut être sanctionné.

7.40 Percuter un deux-roues

Les motos et vélos offrent beaucoup moins de protection.

Les joueurs doivent en tenir compte avant de volontairement les percuter.

Une collision volontaire à haute vitesse peut être considérée comme une action potentiellement létale.

7.41 Deux-roues

Les conducteurs de motos doivent eux aussi respecter la cohérence.

Ils ne doivent pas utiliser systématiquement :

  • escaliers ;
  • ruelles impossibles ;
  • montagnes ;
  • passages extrêmement étroits

uniquement parce que leur véhicule permet techniquement de le faire.

7.42 Casque

Lorsqu’un personnage conduit une moto à vitesse importante, le port d’un casque doit être cohérent.

Les conséquences d’un accident peuvent être plus importantes lorsqu’il n’en porte pas.

7.43 Conduite après blessure

Un joueur gravement blessé ne doit pas automatiquement être capable de conduire normalement.

Le Pain RP reste applicable au volant.

7.44 Tir depuis un véhicule

Les tirs depuis un véhicule doivent être justifiés par une véritable scène.

Ils ne doivent pas transformer une poursuite en Deathmatch mobile.

7.45 Drive-by

Un Drive-by doit avoir un contexte criminel sérieux.

Effectuer des tirs depuis un véhicule sans interaction ou raison suffisante pourra être considéré comme du RDM.

7.46 Tir sur un véhicule

Tirer sur un véhicule en mouvement représente une action potentiellement létale.

Les joueurs doivent prendre en compte le risque pour :

  • le conducteur ;
  • les passagers ;
  • les personnes autour.
7.47 Tir sur les pneus

Les tirs sur les pneus doivent être utilisés avec cohérence.

Ils peuvent entraîner une perte de contrôle importante et ne doivent pas être banalisés.

7.48 Véhicules blindés

Un véhicule blindé ne rend pas ses occupants invincibles.

À l’inverse, les joueurs doivent respecter les protections réellement offertes par le véhicule.

7.49 Véhicules spéciaux

Les véhicules spéciaux, militaires ou particulièrement puissants peuvent être soumis à des règles spécifiques.

Leur simple disponibilité technique ne signifie pas qu’ils peuvent être utilisés librement.

7.50 Hélicoptères

Un hélicoptère doit être utilisé de manière cohérente.

Le pilote doit tenir compte :

  • de son expérience ;
  • de la météo ;
  • de la visibilité ;
  • de la zone ;
  • des obstacles.
7.51 Atterrissages

Un hélicoptère ne doit pas être posé n’importe où uniquement pour gagner du temps.

La zone doit permettre un atterrissage raisonnable.

7.52 Hélicoptère en poursuite

Un hélicoptère peut servir au suivi d’une poursuite lorsqu’il est utilisé par un service ou groupe disposant de cette capacité.

Il ne doit pas devenir un moyen permettant de suivre un joueur sans limite ni conséquence.

7.53 Avions

L’utilisation d’un avion doit respecter les mêmes principes de cohérence.

Les décollages et atterrissages doivent se faire dans des zones adaptées sauf situation exceptionnelle.

7.54 Crash aérien

Un crash d’avion ou d’hélicoptère doit être traité comme une scène extrêmement grave.

Repartir immédiatement après un crash majeur est incohérent.

7.55 Bateaux

La conduite maritime doit également rester cohérente.

Les bateaux ne doivent pas être utilisés pour traverser des zones impossibles ou contourner artificiellement les systèmes du serveur.

7.56 Abandon d’un véhicule

Un véhicule abandonné après une activité criminelle peut devenir un élément d’enquête.

Les joueurs ne doivent pas considérer qu’un véhicule disparaît simplement parce qu’ils ont quitté la zone.

7.57 Nettoyage de preuves

La suppression ou dissimulation d’éléments liés à un véhicule doit passer par des actions ou systèmes RP lorsque ceux-ci existent.

Une simple disparition mécanique ne doit pas automatiquement effacer toutes les conséquences.

7.58 Véhicule détruit

Lorsqu’un véhicule est considéré comme totalement détruit, il ne doit pas être remis en circulation immédiatement dans la même scène.

7.59 Respawn de véhicule

Le respawn d’un véhicule ne doit pas être utilisé pour contourner :

  • une saisie ;
  • une poursuite ;
  • une destruction ;
  • une enquête ;
  • une scène en cours.
7.60 Véhicules saisis

Un véhicule saisi doit respecter les procédures prévues par le serveur.

Le propriétaire ne doit pas chercher à contourner la saisie par un exploit ou une mécanique externe.

7.61 Vol d’un véhicule de police

Le vol d’un véhicule de police doit avoir une véritable justification RP.

Il ne doit pas devenir un réflexe simplement parce qu’un véhicule est laissé ouvert.

7.62 Vol d’une ambulance

La même logique s’applique aux ambulances.

Leur vol doit rester exceptionnel et cohérent avec une scène.

7.63 Carjacking

Un Carjacking doit être traité comme une véritable agression RP.

Le joueur doit laisser une possibilité de réaction lorsque la situation le permet.

7.64 Collision volontaire avec un joueur

Percuter volontairement un personnage à pied doit respecter les règles concernant le VDM.

Un véhicule peut devenir une arme mortelle et doit être traité comme tel.

7.65 Course illégale

Les courses clandestines sont autorisées lorsqu’elles génèrent du RP.

Elles doivent prendre en compte :

  • les risques ;
  • la police ;
  • la circulation ;
  • les accidents ;
  • l’organisation ;
  • les récompenses.
7.66 Courses en ville

Organiser une course en pleine zone fortement fréquentée représente un risque RP important.

Le Mass RP doit être pris en compte.

7.67 Véhicules de course

Les joueurs doivent respecter les caractéristiques de leur véhicule.

Un véhicule préparé peut être performant, mais ne devient pas capable d’ignorer toutes les contraintes physiques.

7.68 Tuning et performances

Les modifications mécaniques ou esthétiques disponibles sur le serveur sont considérées comme RP.

Un joueur ne doit pas inventer des performances absentes du véhicule.

7.69 Utilisation de véhicules pour bloquer une entrée

Bloquer temporairement une entrée peut être cohérent dans une scène.

Le blocage total et permanent d’un bâtiment ou d’un joueur uniquement pour empêcher toute interaction est interdit.

7.70 Principe fondamental des véhicules

Une poursuite réussie n’est pas forcément celle où l’on échappe à la police ou où l’on arrête le suspect.

Une bonne poursuite est celle où les participants produisent une scène crédible, dangereuse et mémorable sans chercher à exploiter les limites de GTA V.

Le véhicule est un outil de Roleplay, pas une excuse pour ignorer toute logique physique.
